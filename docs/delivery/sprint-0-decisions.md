# Decisions Sprint 0

Les decisions suivantes doivent etre arbitrees avant de developper les parcours metier sensibles.

- Fournisseur Mobile Money principal et capacite de remboursement.
- Methode de remboursement MVP sans Wallet : manuel, Mobile Money API ou cash agence.
- Politique de priorite des regles de tarification dynamique.
- Arrondis, devise et duree du devis tarifaire.
- Traitement fiscal national/international, taux et groupe MECeF valides.
- Mode degrade MECeF autorise ou non avant production.
- Source GPS des bus et frequence d'envoi.
- SDK P501, disponibilite des terminaux et format billet 58 mm.
- Lignes, agences et departs inclus dans le pilote.
- Seuil d'ecart de caisse necessitant validation responsable.
