# Préférences utilisateur

Chaque utilisateur peut configurer ses canaux de notification, sa langue et son thème d'affichage. Les préférences sont stockées côté serveur et synchronisées entre appareils.

## Préférences push et inbox

`push_notifications` est le réglage du compte qui autorise les notifications push. Il ne crée pas de token FCM et ne remplace pas la permission système du téléphone. L’inscription d’un token se fait par appareil, depuis l’application mobile, après consentement explicite ; voir le [guide des notifications](/guides/notifications).

Les notifications disponibles dans l’inbox sont persistées côté serveur. Le push est un canal de livraison complémentaire : l’inbox continue de fonctionner si l’utilisateur refuse la permission, si aucun appareil n’est inscrit ou si Firebase est indisponible.

## Canaux de notification

| Canal | Champ | Description |
|-------|-------|-------------|
| Push | `push_notifications` | Autorise l’envoi push FCM vers les appareils inscrits du compte |
| WhatsApp | `whatsapp_notifications` | Messages WhatsApp — rappel de départ, changements |
| Email | `email_notifications` | Emails — confirmations, reçus |

## Consulter

```dart
final res = await authDio.get('/api/v1/auth/preferences');
final prefs = res.data['data'];
print(prefs['push_notifications']); // true
```

## Modifier

```dart
await authDio.put('/api/v1/auth/preferences', data: {
  'push_notifications': true,
  'whatsapp_notifications': false,
  'email_notifications': true,
  'locale': 'fr',
  'theme': 'dark',
});
```

<Note>
  Les modifications sont **partielles** : vous pouvez envoyer uniquement les champs à modifier. Les champs omis conservent leur valeur actuelle. Désactiver `push_notifications` retire également les tokens push enregistrés sur les appareils du compte.
</Note>

## Langue et thème

| Préférence | Valeurs | Description |
|------------|---------|-------------|
| `locale` | `fr`, `en` | Langue des messages et emails |
| `theme` | `light`, `dark`, `system` | Thème d'affichage préféré |

Voir la référence : [Préférences](/reference/auth/preferences-get).
