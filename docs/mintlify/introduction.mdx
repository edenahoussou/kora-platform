**KORA BUS** est la plateforme de transport interurbain du MVP validé par le client. Cette documentation s'adresse aux **développeurs** intégrant l'API REST V1 dans :

- **KORA App Passager** — application mobile client (Flutter) : recherche, réservation, paiement, billet, suivi.
- **KORA OPS Mobile / P501** — application terrain interne (Android) : planning, manifeste, scan, embarquement.
- **Intégrations tierces** — tout système consommant l'API publique KORA BUS.
