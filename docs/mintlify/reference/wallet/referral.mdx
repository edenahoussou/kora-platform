---
title: Rattacher un code de parrainage
description: "Rattache un code au Wallet du voyageur connecté si celui-ci n’a encore ni parrain ni utilisation de billet comptabilisée."
api: POST /api/v1/wallet/referral
---

Rattache un code au Wallet du voyageur connecté si celui-ci n’a encore ni parrain ni utilisation de billet comptabilisée. Le parrain est notifié après le rattachement. Il reçoit le bonus de parrainage au premier billet utilisé par le filleul.

## Paramètres

<ParamField body="referral_code" type="string" required>
  Code reçu du parrain, 24 caractères maximum. Les espaces périphériques et la casse sont ignorés.
</ParamField>

## Réponse

<ResponseField name="data" type="object" required>
  Wallet mis à jour. Consultez les [champs du Wallet](/reference/wallet/overview).
</ResponseField>

<ResponseField name="data.referred_by" type="boolean" required>
  Vaut `true` après le rattachement.
</ResponseField>

<ResponseField name="data.referral_code" type="string" required>
  Code personnel du voyageur connecté, à partager avec ses futurs filleuls.
</ResponseField>

## Codes de réponse

| Code | Description |
|------|-------------|
| `200` | Parrain rattaché au Wallet. |
| `401` | Jeton de session absent ou invalide. |
| `422` | Code obligatoire, invalide, inconnu, code personnel, parrain déjà rattaché ou premier usage déjà enregistré. Le détail figure dans `errors.referral_code`. |

Le mobile peut aussi [envoyer le code à l’inscription](/reference/auth/register-complete) lors de la création d’un nouveau compte.
