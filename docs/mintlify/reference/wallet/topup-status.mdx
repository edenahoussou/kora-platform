---

Consulte le statut d’une recharge après son initiation ou après le retour du parcours de paiement. Arrêtez la consultation périodique quand `data.status` vaut `confirmed` ou `failed`.

## Paramètres

<ParamField path="uuid" type="UUID" required>
  UUID de la recharge retourné par l’endpoint d’initiation.
</ParamField>

## Réponse

<ResponseField name="data.uuid" type="UUID" required>
  Identifiant de la recharge à utiliser pour consulter son statut.
</ResponseField>

<ResponseField name="data.amount" type="integer" required>
  Montant de la recharge en FCFA.
</ResponseField>

<ResponseField name="data.status" type="string" required>
  État de la recharge parmi `pending`, `confirmed` et `failed`. Les deux derniers sont terminaux.
</ResponseField>

<ResponseField name="data.payment" type="object">
  Détails du paiement associé, ou `null`.
</ResponseField>

<ResponseField name="data.payment.uuid" type="UUID">
  Identifiant du paiement associé.
</ResponseField>

<ResponseField name="data.payment.status" type="string">
  État du paiement.
</ResponseField>

<ResponseField name="data.payment.provider" type="string">
  Prestataire de paiement.
</ResponseField>

<ResponseField name="data.payment.provider_reference" type="string">
  Référence du prestataire ou `null`.
</ResponseField>

<ResponseField name="data.payment.next_action" type="string">
  Action indiquée par le serveur parmi `open_widget`, `open_url`, `verify`, `wait`, `done` et `retry`.
</ResponseField>

<ResponseField name="data.payment.widget" type="object">
  Configuration du paiement pour `open_widget`.
</ResponseField>

<ResponseField name="data.payment.checkout_url" type="string">
  URL de paiement à ouvrir pour `open_url`.
</ResponseField>

<ResponseField name="data.payment.polling_interval_seconds" type="integer">
  Intervalle entre les consultations de statut.
</ResponseField>

<ResponseField name="data.payment.failure" type="object">
  Détails de l’échec si disponibles, avec `code`, `message`, `retryable` et `diagnostic_reference`.
</ResponseField>

<ResponseField name="data.created_at" type="string" required>
  Date de création au format ISO 8601.
</ResponseField>

## Codes de réponse

| Code | Description |
|------|-------------|
| `200` | Recharge et état du paiement retournés. |
| `401` | Jeton de session absent ou invalide. |
| `403` | Accès au paiement associé refusé. |
| `404` | Aucune recharge avec cet UUID pour le voyageur connecté. |
