title: Moyens de paiement disponibles
description: "GET /api/v1/payments/methods : catalogue des moyens de paiement Mobile Money activés (FedaPay, MTN MoMo, réseaux) pour l'app passager KORA BUS."
api: GET /api/v1/payments/methods
---

Retourne le catalogue public des moyens de paiement activés pour le Bénin. Le mobile doit afficher uniquement les providers et réseaux présents dans cette réponse. Aucune clé secrète n'est exposée.

## Paramètres

Aucun paramètre de corps. Authentification `Bearer` requise.

<RequestExample>

```bash cURL
curl -X GET https://staging.koraexpress.app/api/v1/payments/methods \
  -H 'Authorization: Bearer 1|aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789abcdef' \
  -H 'Accept: application/json'
```

```javascript JavaScript
const res = await fetch('https://staging.koraexpress.app/api/v1/payments/methods', {
  headers: { 'Authorization': `Bearer ${token}` },
});
const { data } = await res.json();
```

```typescript TypeScript
const res = await fetch('https://staging.koraexpress.app/api/v1/payments/methods', {
  headers: { 'Authorization': `Bearer ${token}` },
});
const data: PaymentCatalog = (await res.json()).data;
```

```dart Dart
final res = await authDio.get('/api/v1/payments/methods');
final methods = res.data['data']['methods'];
```

</RequestExample>

## Réponse

<ResponseField name="data" type="object" required>
  <ResponseField name="data.country" type="string" required>Code pays ISO 3166-1 alpha-2. Toujours `BJ` au MVP.</ResponseField>
  <ResponseField name="data.currency" type="string" required>Devise KORA (frais facturés au passager). Toujours `XOF`.</ResponseField>
  <ResponseField name="data.methods" type="array" required>Liste des moyens de paiement.</ResponseField>
  <ResponseField name="data.methods[].code" type="string" required>Code du moyen (`mobile_money`, `wallet`).</ResponseField>
  <ResponseField name="data.methods[].label" type="string" required>Libellé affichable.</ResponseField>
  <ResponseField name="data.methods[].enabled" type="boolean" required>`true` si le moyen est activé.</ResponseField>
  <ResponseField name="data.methods[].providers" type="array" required>Providers supportant ce moyen.</ResponseField>
  <ResponseField name="data.methods[].providers[].code" type="string" required>Code provider (`fedapay`, `mtn_momo`).</ResponseField>
  <ResponseField name="data.methods[].providers[].label" type="string" required>Libellé affichable du provider.</ResponseField>
  <ResponseField name="data.methods[].providers[].enabled" type="boolean" required>`true` si le provider a des credentials valides.</ResponseField>
  <ResponseField name="data.methods[].providers[].networks" type="array" required>Réseaux Mobile Money supportés par ce provider.</ResponseField>
  <ResponseField name="data.methods[].providers[].requires" type="array" required>Champs obligatoires à fournir à `POST /payments/initiate`.</ResponseField>
  <ResponseField name="data.methods[].providers[].interaction" type="string" required>`push` (USSD push vers le téléphone) ou `push_or_redirect` (push ou redirection web).</ResponseField>
  <ResponseField name="data.methods[].providers[].polling_interval_seconds" type="integer" required>Intervalle recommandé entre deux vérifications.</ResponseField>
  <ResponseField name="data.methods[].providers[].verification" type="string" required>Toujours `server_verify` — le mobile doit appeler `POST /payments/{uuid}/verify`.</ResponseField>
  <ResponseField name="data.methods[].availability" type="string">Présent uniquement si `enabled=false`. `disabled_until_wallet_ledger` indique que le contrat existe mais que l'activation du ledger est nécessaire.</ResponseField>
</ResponseField>

## Codes de réponse

| Code | Description |
|------|-------------|
| `200` | Catalogue retourné. |
| `401` | Token absent ou invalide. |

<Info>
  Le Wallet est retourné comme connu mais désactivé avec `availability: disabled_until_wallet_ledger`. L'application ne doit pas proposer son parcours avant activation serveur.
</Info>
