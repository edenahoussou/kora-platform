# Consulter un paiement

Retourne le statut courant d'un paiement via `PaymentResource`. La relation `reservation` est **toujours chargée** dans cet endpoint (`loadMissing(['reservation.departure'])`). À appeler après `POST /payments/{uuid}/verify` pour rafraîchir l'état jusqu'à l'émission des billets.

## Paramètres

<ParamField path="payment_uuid" type="UUID" required>
  UUID du paiement (route model binding sur colonne `uuid`).
</ParamField>

<RequestExample>

```bash cURL

  -H 'Authorization: Bearer 1|aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789abcdef' \
  -H 'Accept: application/json'
```

```javascript JavaScript
const res = await fetch('https://staging.koraexpress.app/api/v1/payments/9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb80', {
```

## Réponse

<ResponseField name="data" type="Payment" required>
  <ResponseField name="uuid" type="UUID" required>UUID du paiement.</ResponseField>
  <ResponseField name="status" type="string" required>`pending`, `confirmed`, `failed`, `cancelled`, ou `refunded`.</ResponseField>
  <ResponseField name="amount" type="integer" required>Montant.</ResponseField>
  <ResponseField name="currency" type="string" required>Devise.</ResponseField>
  <ResponseField name="provider" type="string" required>Provider.</ResponseField>
  <ResponseField name="provider_reference" type="string">Référence provider ou `null`.</ResponseField>
  <ResponseField name="confirmed_at" type="string">Date de confirmation (ISO 8601) ou `null`.</ResponseField>
  <ResponseField name="expires_at" type="string">Expiration du hold (ISO 8601) ou `null`.</ResponseField>
  <ResponseField name="polling_interval_seconds" type="integer" required>Toujours `10`.</ResponseField>
  <ResponseField name="reservation" type="object" required>Toujours présent dans cet endpoint (relation chargée via `loadMissing`).</ResponseField>
  <ResponseField name="reservation.uuid" type="UUID" required>UUID de la réservation.</ResponseField>
  <ResponseField name="reservation.status" type="string" required>`held`, `confirmed`, `paid`, `ticketed`, `boarded`, `cancelled`, ou `expired`.</ResponseField>
  <ResponseField name="reservation.departure_uuid" type="UUID">UUID du départ ou `null`.</ResponseField>
  <ResponseField name="reservation.ticket_issuance" type="object">État asynchrone de l'émission du billet.</ResponseField>
</ResponseField>

## Statuts de paiement

| Statut | Description |
|--------|-------------|
| `pending` | Paiement initié, en attente de confirmation provider |
| `confirmed` | Paiement confirmé par le provider (webhook) |
| `failed` | Paiement échoué ou réservation expirée avant confirmation |
| `cancelled` | Paiement annulé |
| `refunded` | Paiement remboursé |

## Codes de réponse

| Code | Description |
|------|-------------|
| `200` | Paiement retourné. |
| `401` | Token absent ou invalide. |
| `403` | Paiement appartenant à un autre utilisateur. |
| `404` | Paiement introuvable. |

<Info>
  Appelez `POST /payments/{uuid}/verify`, puis rafraîchissez avec ce GET toutes les `polling_interval_seconds` (10s). Évitez un polling trop agressif pour respecter le rate limit.
</Info>
