# Consulter un billet

Retourne un billet individuel via `TicketResource`. Le billet est rattaché à une réservation ; l'utilisateur authentifié doit en être le propriétaire.

## Paramètres

<ParamField path="ticket_uuid" type="UUID" required>
  UUID public du billet (route model binding sur colonne `uuid`).
</ParamField>

<RequestExample>

```bash cURL
curl -X GET https://staging.koraexpress.app/api/v1/tickets/f1a2b3c4-d5e6-7890-abcd-ef1234567890 \
  -H 'Authorization: Bearer 1|aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789abcdef' \
  -H 'Accept: application/json'
```

```javascript JavaScript
const res = await fetch('https://staging.koraexpress.app/api/v1/tickets/f1a2b3c4-d5e6-7890-abcd-ef1234567890', {
  headers: { 'Authorization': `Bearer ${token}` },
});
const { data } = await res.json();
```

```typescript TypeScript
const res = await fetch(`https://staging.koraexpress.app/api/v1/tickets/${ticketUuid}`, {
  headers: { 'Authorization': `Bearer ${token}` },
});
const data: Ticket = (await res.json()).data;
```

```dart Dart
final res = await authDio.get('/api/v1/tickets/$ticketUuid');
final ticket = res.data['data'];
```

</RequestExample>

## Réponse

<ResponseField name="data" type="Ticket" required>
  <ResponseField name="uuid" type="UUID" required>UUID public du billet.</ResponseField>
  <ResponseField name="short_code" type="string" required>Code court lisible (ex: `KORA-AB12CD`).</ResponseField>
  <ResponseField name="qr_code" type="string" required>Token QR encodé (data URI ou payload brut).</ResponseField>
  <ResponseField name="status" type="string" required>Statut du billet : `issued`, `voided`, `refunded`, etc.</ResponseField>
  <ResponseField name="issued_at" type="string">Date d'émission (ISO 8601) ou `null`.</ResponseField>
  <ResponseField name="reservation_uuid" type="UUID" required>UUID de la réservation parent.</ResponseField>
  <ResponseField name="passenger" type="object">Passager rattaché au billet ou `null`.</ResponseField>
  <ResponseField name="passenger.uuid" type="UUID">UUID du passager.</ResponseField>
  <ResponseField name="passenger.first_name" type="string">Prénom.</ResponseField>
  <ResponseField name="passenger.last_name" type="string">Nom.</ResponseField>
  <ResponseField name="segments" type="array" required>Un segment de billet par leg, trié par `leg_order` 1-based.</ResponseField>
  <ResponseField name="segments[].leg_order" type="integer" required>Ordre du leg, à partir de `1`.</ResponseField>
  <ResponseField name="segments[].departure_uuid" type="UUID">UUID public du départ.</ResponseField>
  <ResponseField name="segments[].origin_stop_uuid" type="UUID">UUID public de l'origine du segment.</ResponseField>
  <ResponseField name="segments[].destination_stop_uuid" type="UUID">UUID public de la destination du segment.</ResponseField>
  <ResponseField name="segments[].seat_uuid" type="UUID">UUID public du siège.</ResponseField>
  <ResponseField name="segments[].seat_code" type="string">Code du siège attribué ou `null`.</ResponseField>
  <ResponseField name="segments[].status" type="string">Statut du segment.</ResponseField>
</ResponseField>

## Codes de réponse

| Code | Description |
|------|-------------|
| `200` | Billet retourné. |
| `401` | Token absent ou invalide. |
| `403` | Le billet appartient à une réservation d'un autre utilisateur. |
| `404` | Billet introuvable. |
