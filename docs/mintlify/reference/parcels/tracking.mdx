---
title: Suivre un colis par référence
description: "GET /api/v1/parcels/tracking/{reference} retourne le contrat public de suivi, sans PII ni secrets."
api: GET /api/v1/parcels/tracking/{reference}
authMethod: none
---

Contrat public minimal pour la page de suivi et le QR. Il contient la référence, le statut, le trajet, le poids, l’échéance de retrait, l’ETA, le dernier événement et les jalons publics.

## Paramètres

<ParamField path="reference" type="string" required>
  Référence logistique au format `KC-YYYYMMDD-#####`.
</ParamField>

## Requête

<RequestExample>

```bash cURL
curl -X GET 'https://staging.koraexpress.app/api/v1/parcels/tracking/KC-20260101-00001' \
  -H 'Accept: application/json'
```

```dart Dart
final response = await dio.get('/api/v1/parcels/tracking/$reference');
final tracking = response.data['data'];
```

</RequestExample>

## Règles

- Le payload ne contient jamais `sender_name`, `recipient_name`, téléphone, `contents`, code de retrait, hash ou payload prestataire.
- `timeline` ne contient que des jalons whitelistés : `preregistered`, `weighed`, `registered`, `ready`, `assigned`, `loaded`, `in_transit`, `unloaded`, `available`, `withdrawn`.
- Un incident bloquant apparaît comme statut `incident`, sans kind, description ni responsable OPS.
- Une référence inconnue renvoie `404`, sans révéler de données de colis.

## Codes de réponse

| Code | Corps / message |
|---|---|
| `200` | Suivi public. |
| `404` | `{"message":"Not Found"}` |
| `429` | `{"message":"Too Many Attempts."}` |

## Sécurité

Aucune authentification. La réponse ne contient que des identifiants publics et aucun nom, téléphone, contenu, code de retrait, hash ou payload prestataire. Limité à 15 requêtes par minute. En local avec `APP_DEBUG=true`, Laravel peut ajouter `exception`, `file`, `line` et `trace` à une erreur `404`. Ce n’est pas le contrat public : la production doit garder `APP_DEBUG=false` et ne renvoyer que `message: Not Found`.
