---
title: Annuler un colis pré-enregistré ou pesé
description: "POST /api/v1/parcels/{parcel_uuid}/cancel annule un colis encore annulable, avec un message 409 explicite sinon."
api: POST /api/v1/parcels/{parcel_uuid}/cancel
---

Annule uniquement un colis encore au statut `preregistered` ou `weighed`, avant paiement. Un colis refusé, payé, affecté, en transit ou remis ne peut jamais être annulé par cette opération.

## Paramètres

<ParamField path="parcel_uuid" type="UUID" required>
  UUID public du colis.
</ParamField>

## Requête

<RequestExample>

```bash cURL
curl -X POST 'https://staging.koraexpress.app/api/v1/parcels/00000000-0000-4000-8000-000000000010/cancel' \
  -H 'Authorization: Bearer $KORA_TOKEN' \
  -H 'Accept: application/json'
```

```dart Dart
final response = await dio.post('/api/v1/parcels/$uuid/cancel', options: Options(headers: {
  'Authorization': 'Bearer $token',
}));
final parcel = response.data['data'];
```

</RequestExample>

## Règles

- Le premier appel annule le colis et retourne le statut `cancelled`.
- Un second appel renvoie `409` avec `Le colis ne peut pas être annulé dans son statut actuel.`
- L’annulation ne rembourse pas un paiement déjà confirmé ; ce cas est refusé par le statut.
- Le code de retrait et les hashes ne sont jamais retournés.

## Codes de réponse

| Code | Corps / message |
|---|---|
| `200` | Colis annulé. |
| `401` | `{"message":"Unauthenticated."}` |
| `403` | `{"message":"This action is unauthorized."}` |
| `404` | `{"message":"Not Found"}` |
| `409` | `{"message":"Le colis ne peut pas être annulé dans son statut actuel."}` |

## Sécurité

`Authorization: Bearer <token Sanctum>` requis. Le titulaire doit posséder `parcels.customer`. Un tiers reçoit `404`, jamais l’existence du colis.
