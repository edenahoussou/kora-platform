---
title: Suivre un colis via un lien partagé
description: "GET /api/v1/parcels/shared/{token} retourne exactement le même payload public que le suivi par référence."
api: GET /api/v1/parcels/shared/{token}
authMethod: none
---

Le jeton de partage est opaque (48 caractères) et seul son hash SHA-256 est stocké. La révocation invalide immédiatement l’ancien lien. Le payload est identique au suivi public par référence.

## Paramètres

<ParamField path="token" type="string" required>
  Jeton opaque de 48 caractères, retourné par `POST /share`.
</ParamField>

## Requête

<RequestExample>

```bash cURL
curl -X GET 'https://staging.koraexpress.app/api/v1/parcels/shared/AbCdEfGhIjKlMnOpQrStUvWxYz0123456789ABCDEFGHIJKL' \
  -H 'Accept: application/json'
```

```dart Dart
final response = await dio.get('/api/v1/parcels/shared/$token');
final tracking = response.data['data'];
```

</RequestExample>

## Règles

- Le jeton est public mais opaque ; il ne doit pas être confondu avec un UUID de colis.
- Un jeton révoqué ou inconnu renvoie `404`.
- Le payload est strictement identique au suivi par référence, sans PII.
- La création et la révocation du jeton sont réservées au propriétaire.

## Codes de réponse

| Code | Corps / message |
|---|---|
| `200` | Suivi public. |
| `404` | `{"message":"Not Found"}` |
| `429` | `{"message":"Too Many Attempts."}` |

## Sécurité

Aucune authentification. La réponse ne contient que des identifiants publics et aucun nom, téléphone, contenu, code de retrait, hash ou payload prestataire. Limité à 15 requêtes par minute. En local avec `APP_DEBUG=true`, Laravel peut ajouter `exception`, `file`, `line` et `trace` à une erreur `404`. Ce n’est pas le contrat public : la production doit garder `APP_DEBUG=false` et ne renvoyer que `message: Not Found`.
