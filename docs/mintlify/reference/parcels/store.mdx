---
title: Pré-enregistrer un colis
description: "POST /api/v1/parcels crée un colis en dépôt direct, avec idempotence obligatoire."
api: POST /api/v1/parcels
---

Crée un colis en dépôt direct. Fournir soit un `corridor_uuid`, soit la paire `deposit_hub_uuid` + `destination_hub_uuid`. `idempotency_key` est obligatoire : le rejeu exact renvoie `200` avec le même colis ; un rejeu avec un poids différent renvoie `409`.

## Paramètres

<ParamField body="corridor_uuid" type="UUID">
  Corridor ouvert pour le trajet. Alternative : fournir `deposit_hub_uuid` et `destination_hub_uuid`.
</ParamField>

<ParamField body="deposit_hub_uuid" type="UUID">
  Hub de dépôt, requis si `corridor_uuid` est absent.
</ParamField>

<ParamField body="destination_hub_uuid" type="UUID">
  Hub de destination, requis si `corridor_uuid` est absent.
</ParamField>

<ParamField body="idempotency_key" type="UUID" required>
  Clé unique par tentative de création.
</ParamField>

<ParamField body="weight_grams" type="integer" required>
  Poids déclaré, entre `1` et `1000000`.
</ParamField>

<ParamField body="sender_name" type="string" required>
  Nom de l’expéditeur.
</ParamField>

<ParamField body="sender_phone" type="string">
  Téléphone de l’expéditeur, si différent du compte.
</ParamField>

<ParamField body="recipient_name" type="string" required>
  Nom du destinataire.
</ParamField>

<ParamField body="recipient_phone" type="string" required>
  Téléphone du destinataire.
</ParamField>

<ParamField body="contents" type="string" required>
  Description factuelle du contenu, sans code de retrait.
</ParamField>

## Corps de la requête

<RequestExample>

```bash cURL
curl -X POST 'https://staging.koraexpress.app/api/v1/parcels' \
  -H 'Authorization: Bearer $KORA_TOKEN' \
  -H 'Accept: application/json' \
  -H 'Content-Type: application/json' \
  --data '{"corridor_uuid":"00000000-0000-4000-8000-000000000001","idempotency_key":"00000000-0000-4000-8000-000000000099","weight_grams":5000,"sender_name":"Expéditeur Exemple","sender_phone":"+22900000000","recipient_name":"Destinataire Exemple","recipient_phone":"+22900000001","contents":"Documents"}'
```

## Règles

- Fournir soit `corridor_uuid`, soit `deposit_hub_uuid` + `destination_hub_uuid`. La paire de hubs permet un dépôt direct sans corridor préexistant.
- `201` à la création ; `200` si la même clé est rejouée avec exactement le même contenu.
- Un rejeu avec un poids différent renvoie `409` et ne crée pas de second colis.
- Le colis est créé au statut `preregistered` ; il n’est pas encore pesé ni payé.
- `reference` peut déjà être présente, mais le code de retrait et le hash ne sont jamais retournés.

## Codes de réponse

| Code | Corps / message |
|---|---|
| `201` | Colis créé. |
| `200` | Rejeu exact de la même clé. |
| `401` | `{"message":"Unauthenticated."}` |
| `403` | `{"message":"This action is unauthorized."}` |
| `409` | `{"message":"This idempotency key was already used with different intake data."}` |
| `422` | `{"message":"Le champ weight grams doit être au moins 1.","errors":{"weight_grams":["Le champ weight grams doit être au moins 1."]}}` |
| `429` | `{"message":"Too Many Attempts."}` |

## Sécurité

`Authorization: Bearer <token Sanctum>` requis. Le titulaire doit posséder `parcels.customer`. Un tiers reçoit `404`, jamais l’existence du colis. Limité à 20 requêtes par minute.
