---
title: Lister les moyens de paiement du colis
description: "GET /api/v1/parcels/{parcel_uuid}/payment-methods retourne les moyens autorisés pour le corridor, sans cash côté client."
api: GET /api/v1/parcels/{parcel_uuid}/payment-methods
---

Retourne le pays, la devise et les moyens autorisés pour le corridor. Les prestataires sont filtrés par pays et les capacités Wallet par corridor. L’application cliente ne propose pas `cash`.

## Paramètres

<ParamField path="parcel_uuid" type="UUID" required>
  UUID public du colis.
</ParamField>

## Requête

<RequestExample>

```bash cURL
curl -X GET 'https://staging.koraexpress.app/api/v1/parcels/00000000-0000-4000-8000-000000000010/payment-methods' \
  -H 'Authorization: Bearer $KORA_TOKEN' \
  -H 'Accept: application/json'
```

```dart Dart
final response = await dio.get('/api/v1/parcels/$uuid/payment-methods', options: Options(headers: {
  'Authorization': 'Bearer $token',
}));
final methods = response.data['data']['methods'] as List;
```

</RequestExample>

## Règles

- `cash` n’est pas un moyen client : il reste réservé au guichet OPS.
- Un moyen `enabled=false` ne doit pas être proposé, même s’il apparaît dans le catalogue filtré.
- `wallet` peut être `availability: points_only` selon le corridor et `point_value_fcfa`.
- Les prestataires absents du pays du corridor sont retirés de `providers`.

## Codes de réponse

| Code | Corps / message |
|---|---|
| `200` | Moyens de paiement filtrés. |
| `401` | `{"message":"Unauthenticated."}` |
| `403` | `{"message":"This action is unauthorized."}` |
| `404` | `{"message":"Not Found"}` |

## Sécurité

`Authorization: Bearer <token Sanctum>` requis. Réservé à l’expéditeur propriétaire. Un tiers reçoit `404`.
