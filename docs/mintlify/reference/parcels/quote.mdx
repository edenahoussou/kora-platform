description: "POST /api/v1/parcels/quote calcule un devis TTC autoritatif pour un corridor et un poids déclaré."
api: POST /api/v1/parcels/quote
authMethod: none
---

Endpoint public de devis. Le client envoie un corridor et un poids ; il ne doit jamais envoyer un montant. Le serveur retourne les paliers, la TVA et le total TTC.

## Paramètres

<ParamField body="corridor_uuid" type="UUID" required>
  Corridor retourné par `GET /api/v1/parcels/corridors`.
</ParamField>

<ParamField body="weight_grams" type="integer" required>
  Poids déclaré en grammes, entre `1` et `1000000`.
</ParamField>

## Corps de la requête

<RequestExample>

```bash cURL
curl -X POST 'https://staging.koraexpress.app/api/v1/parcels/quote' \
  -H 'Accept: application/json' \
  -H 'Content-Type: application/json' \
  --data '{"corridor_uuid":"00000000-0000-4000-8000-000000000001","weight_grams":5000}'
```

```dart Dart
final response = await dio.post('/api/v1/parcels/quote', data: {
  'corridor_uuid': corridorUuid,
  'weight_grams': 5000,
});
final quote = response.data['data'];
```

</RequestExample>

## Règles

- `total`, `net` et `tax` sont calculés côté serveur ; le client ne peut pas les imposer.
- Les paliers `tiers` permettent d’afficher le détail du prix sans recalcul local.
- Un poids `0` renvoie `422` ; un corridor fermé ou sans tarif renvoie `409`.
- Le devis est un aperçu avant dépôt. Le montant collectible final est créé après pesée et inspection.

## Codes de réponse

| Code | Corps / message |
|---|---|
| `200` | Devis calculé. |
| `409` | `{"message":"Parcel corridor is unavailable."}` |
| `422` | `{"message":"Le champ weight grams doit être au moins 1.","errors":{"weight_grams":["Le champ weight grams doit être au moins 1."]}}` |
| `429` | `{"message":"Too Many Attempts."}` |

## Sécurité

Aucune authentification. La réponse ne contient que des identifiants publics et aucun nom, téléphone, contenu, code de retrait, hash ou payload prestataire. Limité à 30 requêtes par minute.
