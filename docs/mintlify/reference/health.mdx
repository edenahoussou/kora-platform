# Santé de l'application

Probe de santé complet vérifiant la base de données et le cache. Retourne `ok` si tous les checks passent, `degraded` sinon.

<RequestExample>

```bash cURL
curl -X GET https://staging.koraexpress.app/api/v1/health \
  -H 'Accept: application/json'
```

```javascript JavaScript
const res = await fetch('https://staging.koraexpress.app/api/v1/health');
const data = await res.json();
```

```typescript TypeScript
const res = await fetch('https://staging.koraexpress.app/api/v1/health');
const data: HealthStatus = await res.json();
```

```dart Dart
final res = await dio.get('/api/v1/health');
print(res.data['status']);
```

</RequestExample>

<ResponseExample>

```json 200
{
  "status": "ok",
  "service": "kora-platform",
  "scope": "mvp-bus",
  "version": "v1",
  "timestamp": "2026-08-17T13:05:00.000Z",
  "checks": {
    "database": { "status": "ok", "latency_ms": 12 },
    "cache": { "status": "ok", "latency_ms": 2 }
  }
}
```

```json 503
{
  "status": "degraded",
  "service": "kora-platform",
  "scope": "mvp-bus",
  "version": "v1",
  "timestamp": "2026-08-17T13:05:00.000Z",
  "checks": {
    "database": { "status": "error", "latency_ms": null },
    "cache": { "status": "ok", "latency_ms": 2 }
  }
}
```

</ResponseExample>

## Réponse

<ResponseField name="status" type="string" required>`ok` ou `degraded`.</ResponseField>
<ResponseField name="service" type="string" required>Nom du service (config `kora.service`).</ResponseField>
<ResponseField name="scope" type="string" required>Scope (config `kora.scope`, défaut `mvp-bus`).</ResponseField>
<ResponseField name="version" type="string" required>Version API (config `kora.api_version`, défaut `v1`).</ResponseField>
<ResponseField name="timestamp" type="string" required>Timestamp ISO 8601.</ResponseField>
<ResponseField name="checks.database" type="object" required>
  <ResponseField name="status" type="string" required>`ok` ou `error`.</ResponseField>
  <ResponseField name="latency_ms" type="integer">Latence en ms ou `null`.</ResponseField>
</ResponseField>
<ResponseField name="checks.cache" type="object" required>
  <ResponseField name="status" type="string" required>`ok` ou `error`.</ResponseField>
  <ResponseField name="latency_ms" type="integer">Latence en ms ou `null`.</ResponseField>
</ResponseField>

## Codes de réponse

| Code | Description |
|------|-------------|
| `200` | Application saine (`status: ok`). |
| `503` | Application dégradée (`status: degraded`). |
