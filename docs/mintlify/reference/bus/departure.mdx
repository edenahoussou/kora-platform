# Consulter un départ

Retourne le détail d'un départ : ligne, bus, segment origine/destination, nombre de sièges disponibles et aperçu tarifaire. Accepte `from` et `to` en query pour filtrer les stops.

## Paramètres

<ParamField path="uuid" type="UUID" required>
  UUID du départ.
</ParamField>

<ParamField query="from" type="string">
  Ville d'origine (filtre, max 120).
</ParamField>

<ParamField query="to" type="string">
  Ville de destination (filtre, max 120).
</ParamField>

<RequestExample>

```bash cURL
curl -X GET https://staging.koraexpress.app/api/v1/bus/departures/a3091549-9179-454e-8440-58179f2208df \
  -H 'Accept: application/json'
```

```javascript JavaScript
const res = await fetch('https://staging.koraexpress.app/api/v1/bus/departures/a3091549-9179-454e-8440-58179f2208df');
const { data } = await res.json();
```

```typescript TypeScript
const res = await fetch(`https://staging.koraexpress.app/api/v1/bus/departures/${departureUuid}`);
const data: Departure = (await res.json()).data;
```

```dart Dart
final res = await dio.get('/api/v1/bus/departures/a3091549-9179-454e-8440-58179f2208df');
```

</RequestExample>

| Code | Description |
|------|-------------|

| `404` | Départ introuvable. |
| `429` | Rate limit dépassé. |
