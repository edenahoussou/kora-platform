# Lignes

## Lister les lignes

`GET /api/v1/bus/lines`

Retourne les lignes actives, filtrables par segment origine/destination. Chaque ligne contient ses arrêts ordonnés.

```bash
curl -X GET 'https://api.korabus.app/api/v1/bus/lines?from=Cotonou&to=Abidjan' \
  -H 'Accept: application/json'
```

```javascript
const res = await fetch('https://api.korabus.app/api/v1/bus/lines?from=Cotonou&to=Abidjan');
const { data } = await res.json();
```

```typescript
const res = await fetch('https://api.korabus.app/api/v1/bus/lines?from=Cotonou&to=Abidjan');
const data: KoraLine[] = (await res.json()).data;
```

```dart
final res = await dio.get('/api/v1/bus/lines', queryParameters: {
  'from': 'Cotonou',
  'to': 'Abidjan',
});
final lines = res.data['data'] as List;
```

### Paramètres

| Champ | Type | Requis | Description |
|-------|------|--------|-------------|
| `from` | string (query) | ❌ | Ville d'origine (filtre). |
| `to` | string (query) | ❌ | Ville de destination (filtre). |

| Code | Description |
|------|-------------|
| `200` | Liste des lignes. |
| `429` | Rate limit `bus-search` dépassé. |

<Warning>
  Conservez les `uuid` des arrêts d'origine et de destination — ils sont requis pour l'endpoint sièges et la création de devis.
</Warning>

## Consulter une ligne

`GET /api/v1/bus/lines/{uuid}`

```bash
curl -X GET https://api.korabus.app/api/v1/bus/lines/6ff8f7f6-1eb3-3525-be4a-3932c805afed \
  -H 'Accept: application/json'
```

```dart
final res = await dio.get('/api/v1/bus/lines/6ff8f7f6-1eb3-3525-be4a-3932c805afed');
```

| Code | Description |
|------|-------------|
| `200` | Détail de la ligne. |
| `404` | Ligne introuvable. |
| `429` | Rate limit dépassé. |
