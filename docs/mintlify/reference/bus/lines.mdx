# Lister les lignes

Retourne les lignes actives, filtrables par segment origine/destination. Chaque ligne contient ses arrêts ordonnés si la relation est chargée.

## Paramètres

<ParamField query="from" type="string">
  Ville d'origine (filtre, max 120).
</ParamField>

<ParamField query="to" type="string">
  Ville de destination (filtre, max 120).
</ParamField>

<RequestExample>

```bash cURL
curl -X GET 'https://staging.koraexpress.app/api/v1/bus/lines?from=Cotonou&to=Abidjan' \
  -H 'Accept: application/json'
```

```javascript JavaScript
const res = await fetch('https://staging.koraexpress.app/api/v1/bus/lines?from=Cotonou&to=Abidjan');
const { data } = await res.json();
```

```typescript TypeScript
const res = await fetch('https://staging.koraexpress.app/api/v1/bus/lines?from=Cotonou&to=Abidjan');
const data: Line[] = (await res.json()).data;
```

```dart Dart
final res = await dio.get('/api/v1/bus/lines', queryParameters: {
  'from': 'Cotonou',
  'to': 'Abidjan',
});
final lines = res.data['data'] as List;
```

</RequestExample>

## Réponse

<ResponseField name="data" type="Line[]" required>
  <ResponseField name="uuid" type="UUID" required>Identifiant de la ligne.</ResponseField>
  <ResponseField name="code" type="string" required>Code de la ligne.</ResponseField>
  <ResponseField name="name" type="string" required>Nom de la ligne.</ResponseField>
  <ResponseField name="type" type="string" required>`nationale` ou `internationale`.</ResponseField>
  <ResponseField name="countries_crossed" type="string[]">Pays traversés.</ResponseField>
  <ResponseField name="distance_km" type="integer">Distance en km ou `null`.</ResponseField>
  <ResponseField name="estimated_duration_minutes" type="integer">Durée estimée en minutes ou `null`.</ResponseField>
  <ResponseField name="status" type="string" required>`active`, `draft`, ou `archived`.</ResponseField>
  <ResponseField name="stops" type="Stop[]">Arrêts ordonnés (seulement si relation chargée) ou `null`.</ResponseField>
</ResponseField>

## Codes de réponse

| Code | Description |
|------|-------------|
| `200` | Liste des lignes. |
| `422` | Validation échouée. |

<Warning>
  Conservez les `uuid` des arrêts d'origine et de destination — ils sont requis pour l'endpoint sièges et la création de devis.
</Warning>
