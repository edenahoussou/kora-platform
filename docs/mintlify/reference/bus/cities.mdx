# Lister les villes

Retourne les villes desservies par KORA BUS avec leurs points physiques d'embarquement et de débarquement. Chaque point physique expose son UUID, que le mobile utilise comme `from_physical_stop_uuid` / `to_physical_stop_uuid` dans `GET /api/v1/bus/itineraries`. Aucun paramètre requis.

<RequestExample>

```bash cURL
curl -X GET https://staging.koraexpress.app/api/v1/bus/cities \
  -H 'Accept: application/json'
```

```javascript JavaScript
const res = await fetch('https://staging.koraexpress.app/api/v1/bus/cities');
const { data } = await res.json();
```

```typescript TypeScript
const res = await fetch('https://staging.koraexpress.app/api/v1/bus/cities');
const data: City[] = (await res.json()).data;
```

```dart Dart
final res = await dio.get('/api/v1/bus/cities');
final cities = res.data['data'] as List;
```

</RequestExample>

## Réponse

<ResponseField name="data" type="City[]" required>
  Tableau des villes.

  <ResponseField name="data[].city" type="string" required>Nom de la ville.</ResponseField>
  <ResponseField name="data[].country" type="string" required>Code pays ISO 3166-1 alpha-2.</ResponseField>
  <ResponseField name="data[].physical_stops" type="object[]" required>
    Points physiques d'embarquement/débarquement de la ville.

    <ResponseField name="data[].physical_stops[].uuid" type="UUID" required>
      UUID du point physique. À utiliser comme `from_physical_stop_uuid` ou `to_physical_stop_uuid` dans `GET /api/v1/bus/itineraries`.
    </ResponseField>
    <ResponseField name="data[].physical_stops[].name" type="string" required>
      Nom affichable du point physique (ex: « Cotonou · St Michel »).
    </ResponseField>
  </ResponseField>
</ResponseField>

## Codes de réponse

| Code | Description |
|------|-------------|
| `200` | Liste des villes avec leurs points physiques. |

<Info>
  Appelez cet endpoint au démarrage de l'application pour construire le sélecteur origine/destination. L'utilisateur choisit une ville, puis un point physique, puis une date — le mobile appelle ensuite `GET /api/v1/bus/itineraries` avec les UUIDs sélectionnés.
</Info>
