# Disponibilité des sièges

Retourne la disponibilité de chaque siège pour le **segment O/D** demandé. KORA BUS vend des segments : la disponibilité dépend du segment, pas du départ complet.

## Paramètres

<ParamField path="departure_uuid" type="UUID" required>
  UUID du départ.
</ParamField>

<ParamField query="origin_stop_uuid" type="UUID" required>
  UUID de l'arrêt d'origine du segment.
</ParamField>

<ParamField query="destination_stop_uuid" type="UUID" required>
  UUID de l'arrêt de destination.
</ParamField>

## Réponse

<ResponseField name="data" type="SeatAvailability[]" required>
  <ResponseField name="uuid" type="UUID" required>UUID du siège.</ResponseField>
  <ResponseField name="code" type="string" required>Code du siège (ex: `4A`).</ResponseField>
  <ResponseField name="type" type="string" required>`standard`, `crew`, ou `premium`.</ResponseField>
  <ResponseField name="sellable" type="boolean" required>Si le siège est vendable.</ResponseField>
  <ResponseField name="availability_status" type="string" required>`available`, `occupied`, ou `blocked`.</ResponseField>
</ResponseField>

## Statuts de siège

| Statut | Description | Action client |
|--------|-------------|---------------|
| `available` | Libre sur le segment demandé | Sélectionnable |
| `occupied` | Réservé sur le segment demandé | Non sélectionnable |
| `blocked` | Bloqué (maintenance, équipage, chevauchement) | Non sélectionnable |

## Codes de réponse

| Code | Description |
|------|-------------|
| `200` | Liste des sièges avec disponibilité. |
| `404` | Départ introuvable. |
| `422` | `origin_stop_uuid` ou `destination_stop_uuid` manquant. |
| `429` | Rate limit `bus-search` dépassé. |

<Info>
  Un siège peut être `available` pour Cotonou → Bohicon mais `occupied` pour Cotonou → Abidjan, car un autre passager l'a réservé pour Bohicon → Abidjan.
</Info>
