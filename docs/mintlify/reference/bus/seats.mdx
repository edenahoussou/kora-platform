# Sièges

`GET /api/v1/bus/departures/{departure_uuid}/seats`

Retourne la disponibilité de chaque siège pour le **segment O/D** demandé. KORA BUS vend des segments : la disponibilité dépend du segment, pas du départ complet.

```bash
curl -X GET 'https://api.korabus.app/api/v1/bus/departures/a3091549-9179-454e-8440-58179f2208df/seats?origin_stop_uuid=6b72fe4a-5b40-307c-bc24-f79acf9a1bb9&destination_stop_uuid=8d94f06c-7d62-529e-de46-9bce1cbc3dd1' \
  -H 'Accept: application/json'
```

```javascript
const url = new URL('https://api.korabus.app/api/v1/bus/departures/a3091549-9179-454e-8440-58179f2208df/seats');
url.searchParams.set('origin_stop_uuid', originStopUuid);
url.searchParams.set('destination_stop_uuid', destinationStopUuid);
const res = await fetch(url);
const { data } = await res.json();
const available = data.filter(s => s.availability_status === 'available');
```

```typescript
const res = await fetch(`https://api.korabus.app/api/v1/bus/departures/${departureUuid}/seats?origin_stop_uuid=${originStopUuid}&destination_stop_uuid=${destinationStopUuid}`);
const data: KoraSeat[] = (await res.json()).data;
```

```dart
final res = await dio.get(
```

### Paramètres

| Champ | Type | Requis | Description |
|-------|------|--------|-------------|
| `departure_uuid` | UUID (path) | ✅ | UUID du départ. |
| `origin_stop_uuid` | UUID (query) | ✅ | UUID de l'arrêt d'origine du segment. |
| `destination_stop_uuid` | UUID (query) | ✅ | UUID de l'arrêt de destination. |

### Statuts de siège

| Statut | Description | Action client |
|--------|-------------|---------------|
| `available` | Libre sur le segment demandé | Sélectionnable |
| `occupied` | Réservé sur le segment demandé | Non sélectionnable |
| `blocked` | Bloqué (maintenance, équipage, chevauchement) | Non sélectionnable |

| Code | Description |
|------|-------------|
| `200` | Liste des sièges avec disponibilité. |
| `404` | Départ introuvable. |
| `422` | `origin_stop_uuid` ou `destination_stop_uuid` manquant. |
| `429` | Rate limit `bus-search` dépassé. |

<Info>
  Un siège peut être `available` pour Cotonou → Bohicon mais `occupied` pour Cotonou → Abidjan, car un autre passager l'a réservé pour Bohicon → Abidjan. Voir [Sélection de sièges](/guides/seat-selection).
</Info>
