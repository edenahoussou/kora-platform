# Rechercher des départs

Retourne les départs programmés pour une date et un segment. Le paramètre `date` est **obligatoire** (format `YYYY-MM-DD`).

## Paramètres

<ParamField query="date" type="string" required>
  Date de voyage `YYYY-MM-DD`.
</ParamField>

<ParamField query="from" type="string">
  Ville d'origine (filtre, max 120).
</ParamField>

<ParamField query="to" type="string">
  Ville de destination (filtre, max 120).
</ParamField>

<RequestExample>

```bash cURL
curl -X GET 'https://staging.koraexpress.app/api/v1/bus/departures?date=2026-08-20&from=Cotonou&to=Abidjan' \
  -H 'Accept: application/json'
```

```javascript JavaScript
const res = await fetch('https://staging.koraexpress.app/api/v1/bus/departures?date=2026-08-20&from=Cotonou&to=Abidjan');
const { data } = await res.json();
```

```typescript TypeScript
const res = await fetch('https://staging.koraexpress.app/api/v1/bus/departures?date=2026-08-20&from=Cotonou&to=Abidjan');
const data: Departure[] = (await res.json()).data;
```

```dart Dart
final res = await dio.get('/api/v1/bus/departures', queryParameters: {
  'date': '2026-08-20',
  'from': 'Cotonou',
  'to': 'Abidjan',
});
final departures = res.data['data'] as List;
```

</RequestExample>

  <ResponseField name="departure_date" type="string" required>Date `YYYY-MM-DD`.</ResponseField>

## Codes de réponse

| Code | Description |
|------|-------------|
| `200` | Liste des départs. |
| `422` | `date` manquant ou format invalide. |
| `429` | Rate limit `bus-search` dépassé. |

<Info>
  Le `fare_preview` est un **aperçu** indicatif. Le prix figé et contractuel s'obtient via `POST /api/v1/bus/quotes`.
</Info>
