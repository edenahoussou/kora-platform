# Départs

## Rechercher des départs

`GET /api/v1/bus/departures`

Retourne les départs programmés pour une date et un segment. Le paramètre `date` est **obligatoire**.

```bash
curl -X GET 'https://api.korabus.app/api/v1/bus/departures?date=2026-08-20&from=Cotonou&to=Abidjan' \
  -H 'Accept: application/json'
```

```javascript
const res = await fetch('https://api.korabus.app/api/v1/bus/departures?date=2026-08-20&from=Cotonou&to=Abidjan');
const { data } = await res.json();
```

```typescript
const res = await fetch('https://api.korabus.app/api/v1/bus/departures?date=2026-08-20&from=Cotonou&to=Abidjan');
const data: KoraDeparture[] = (await res.json()).data;
```

```dart
final res = await dio.get('/api/v1/bus/departures', queryParameters: {
  'date': '2026-08-20',
  'from': 'Cotonou',
  'to': 'Abidjan',
});
final departures = res.data['data'] as List;
```

### Paramètres

| Champ | Type | Requis | Description |
|-------|------|--------|-------------|
| `date` | string (query) | ✅ | Date de voyage `YYYY-MM-DD`. |
| `from` | string (query) | ❌ | Ville d'origine. |
| `to` | string (query) | ❌ | Ville de destination. |

| Code | Description |
|------|-------------|
| `200` | Liste des départs. |
| `422` | `date` manquant ou format invalide. |
| `429` | Rate limit `bus-search` dépassé. |

<Info>
  Le `fare_preview` est un **aperçu** indicatif. Le prix figé et contractuel s'obtient via `POST /api/v1/bus/quotes`. N'affichez pas de prix définitif côté client avant la réponse du devis.
</Info>

## Consulter un départ

`GET /api/v1/bus/departures/{uuid}`

```bash
curl -X GET https://api.korabus.app/api/v1/bus/departures/a3091549-9179-454e-8440-58179f2208df \
  -H 'Accept: application/json'
```

```dart
final res = await dio.get('/api/v1/bus/departures/a3091549-9179-454e-8440-58179f2208df');
```

| Code | Description |
|------|-------------|
| `200` | Détail du départ. |
| `404` | Départ introuvable. |
| `429` | Rate limit dépassé. |
