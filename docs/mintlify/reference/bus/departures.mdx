# Rechercher des départs

Retourne les départs programmés pour une date et un segment. Le paramètre `date` est **obligatoire** (format `YYYY-MM-DD`).

## Paramètres

<ParamField query="date" type="string" required>
  Date de voyage `YYYY-MM-DD`.
</ParamField>

<ParamField query="from" type="string">
  Ville d'origine (filtre, max 120).
</ParamField>

<ParamField query="to" type="string">
  Ville de destination (filtre, max 120).
</ParamField>

<RequestExample>

```bash cURL
curl -X GET 'https://staging.koraexpress.app/api/v1/bus/departures?date=2026-08-20&from=Cotonou&to=Abidjan' \
  -H 'Accept: application/json'
```

```javascript JavaScript
const res = await fetch('https://staging.koraexpress.app/api/v1/bus/departures?date=2026-08-20&from=Cotonou&to=Abidjan');
const { data } = await res.json();
```

```typescript TypeScript
const res = await fetch('https://staging.koraexpress.app/api/v1/bus/departures?date=2026-08-20&from=Cotonou&to=Abidjan');
const data: Departure[] = (await res.json()).data;
```

```dart Dart
final res = await dio.get('/api/v1/bus/departures', queryParameters: {
  'date': '2026-08-20',
  'from': 'Cotonou',
  'to': 'Abidjan',
});
final departures = res.data['data'] as List;
```

</RequestExample>

## Réponse

<ResponseField name="data" type="Departure[]" required>
  <ResponseField name="uuid" type="UUID" required>UUID du départ.</ResponseField>
  <ResponseField name="departure_date" type="string" required>Date `YYYY-MM-DD`.</ResponseField>
  <ResponseField name="departure_time" type="string" required>Heure `HH:MM`.</ResponseField>
  <ResponseField name="estimated_arrival_at" type="string">Arrivée estimée (ISO 8601) ou `null`.</ResponseField>
  <ResponseField name="status" type="string" required>`scheduled`, `boarding`, `departed`, `arrived`, ou `cancelled`.</ResponseField>
  <ResponseField name="line" type="Line" required>Ligne du départ.</ResponseField>
  <ResponseField name="bus" type="object" required>Bus assigné.</ResponseField>
  <ResponseField name="origin_stop" type="Stop" required>Arrêt d'origine.</ResponseField>
  <ResponseField name="destination_stop" type="Stop" required>Arrêt de destination.</ResponseField>
  <ResponseField name="available_seats_count" type="integer" required>Sièges disponibles.</ResponseField>
  <ResponseField name="fare_preview" type="object" required>Aperçu tarifaire indicatif.</ResponseField>
</ResponseField>

## Codes de réponse

| Code | Description |
|------|-------------|
| `200` | Liste des départs. |
| `422` | `date` manquant ou format invalide. |
| `429` | Rate limit `bus-search` dépassé. |

<Info>
  Le `fare_preview` est un **aperçu** indicatif. Le prix figé et contractuel s'obtient via `POST /api/v1/bus/quotes`.
</Info>
