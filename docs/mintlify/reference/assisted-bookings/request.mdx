---
title: Envoyer une réservation en assistance
description: POST /api/v1/bookings/{uuid}/assistance adresse la réservation au support central et la place dans la file réseau sans agence initiale.
api: POST /api/v1/bookings/{reservation_uuid}/assistance
---

La réservation existante est transformée : les sièges et le crédit entreprise sont libérés, les segments passent en `requested`, puis le dossier entre dans la file réseau avec le statut `pending`. Aucune agence n’est choisie dans l’application. Le même UUID et la même référence sont conservés.

Le backend renvoie les coordonnées et les liens du support central configurés dans KORA. Les canaux appel et WhatsApp sont indépendants : si le canal demandé n’est pas configuré, la réponse est `503` avec le code `assisted_booking_support_unavailable`; aucune agence ni aucun autre canal ne sert de repli.

## Requête

```bash cURL
curl -X POST https://staging.koraexpress.app/api/v1/bookings/9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb70/assistance \
  -H 'Authorization: Bearer 1|aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789abcdef' \
  -H 'Accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
    "channel": "whatsapp",
    "contact_name": "Afi",
    "contact_phone": "+2290197000000",
    "idempotency_key": "1f3d5b7a-9c2e-4f6a-8b0d-2e4f6a8c0d2f"
  }'
```

## Codes de réponse

| Code | Description |
|------|-------------|
| `201` | Dossier créé dans la file réseau. |
| `200` | Rejeu idempotent : dossier existant retourné. |
| `401` | Token absent ou invalide. |
| `403` | Réservation appartenant à un autre utilisateur. |
| `422` | Réservation ou données de contact non valides. |
| `503` | Le canal central demandé n’est pas configuré (`assisted_booking_support_unavailable`). |

Après création, une agence habilitée peut réclamer le dossier. Le champ `handling_agency` reste nul jusqu’au claim; une réaffectation met le dossier en attente dans la file de l’agence cible, sans sélectionner d’agent.
