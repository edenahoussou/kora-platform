# Lister les agences éligibles

Retourne les agences actives qui exposent au moins un canal de contact public (`call_phone` ou `whatsapp_phone`). Le client mobile n'active un bouton (appel ou WhatsApp) que si le numéro correspondant existe.

<RequestExample>

```bash cURL
curl -X GET https://staging.koraexpress.app/api/v1/assisted-bookings/agencies \
  -H 'Authorization: Bearer 1|aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789abcdef' \
  -H 'Accept: application/json'
```

```javascript JavaScript
const res = await fetch('https://staging.koraexpress.app/api/v1/assisted-bookings/agencies', {
  headers: { 'Authorization': `Bearer ${token}` },
});
const { data } = await res.json();
```

```typescript TypeScript
const res = await fetch('https://staging.koraexpress.app/api/v1/assisted-bookings/agencies', {
  headers: { 'Authorization': `Bearer ${token}` },
});
const agencies: Agency[] = (await res.json()).data;
```

```dart Dart
final res = await authDio.get('/api/v1/assisted-bookings/agencies');
final agencies = res.data['data'];
```

</RequestExample>

<ResponseExample>

```json 200
{
  "data": [

```

</ResponseExample>

## Codes de réponse

| Code | Description |
|------|-------------|
| `200` | Liste des agences éligibles (peut être vide). |
| `401` | Token absent ou invalide. |

<Info>
  Une agence est éligible si elle est `active` et possède au moins un numéro `call_phone` ou `whatsapp_phone`. Aucun lien n'existe entre une agence et un départ, un véhicule ou un arrêt.
</Info>
