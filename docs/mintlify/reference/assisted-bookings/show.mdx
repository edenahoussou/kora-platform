---
title: Consulter un dossier assisté
description: GET /api/v1/bookings/{uuid}/assistance retourne l'état du dossier d'assistance, sa validité, l'agence traitante et les actions encore permises.
api: GET /api/v1/bookings/{reservation_uuid}/assistance
---

Retourne l'état courant du dossier : statut (`pending`, `in_progress`, `cancelled`, `refused`, `unavailable`, `expired`, `finalized`), fenêtre de validité, canaux du support central, snapshot initial et actions encore permises (`actions.resume_online`). `handling_agency` et `assigned_agent` restent nuls avant le claim.

## Paramètres

<ParamField path="reservation_uuid" type="UUID" required>
  UUID de la réservation (route model binding sur colonne `uuid`).
</ParamField>

## Codes de réponse

| Code | Description |
|------|-------------|
| `200` | Dossier retourné. |
| `401` | Token absent ou invalide. |
| `403` | Réservation appartenant à un autre utilisateur. |
| `404` | Aucun dossier d'assistance pour cette réservation. |

<Info>
  `valid_until` correspond au premier cutoff commercial effectif des départs de l'itinéraire. Passée cette date, le dossier passe automatiquement en `expired`.
</Info>
