# Libérer un hold

Libère volontairement le hold de l'utilisateur authentifié. Le statut passe à `cancelled`, les segments sont libérés et `released_at` est renseigné.

## Paramètres

<ParamField path="reservation_uuid" type="UUID" required>
  UUID de la réservation à libérer (route model binding sur colonne `uuid`).
</ParamField>

<RequestExample>

```bash cURL
curl -X DELETE https://staging.koraexpress.app/api/v1/holds/9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb70 \
  -H 'Authorization: Bearer 1|aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789abcdef'
```

```javascript JavaScript
await fetch('https://staging.koraexpress.app/api/v1/holds/9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb70', {
  method: 'DELETE',
  headers: { 'Authorization': `Bearer ${token}` },
});
```

```typescript TypeScript
await fetch(`https://staging.koraexpress.app/api/v1/holds/${reservationUuid}`, {
  method: 'DELETE',
  headers: { 'Authorization': `Bearer ${token}` },
});
```

```dart Dart
await authDio.delete('/api/v1/holds/9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb70');
```

</RequestExample>

## Codes de réponse

| Code | Description |
|------|-------------|
| `204` | Hold libéré — pas de body. |
| `401` | Token absent ou invalide. |
| `403` | Réservation appartenant à un autre utilisateur (policy `cancel`). |

<Warning>
  Un webhook de paiement tardif ne peut **pas** réactiver une réservation expirée : le paiement est marqué `failed` et les segments restent disponibles.
</Warning>
