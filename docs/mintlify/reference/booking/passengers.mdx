# Enregistrer les passagers

Enregistre les voyageurs et associe chaque voyageur à un siège réservé. Le nombre de voyageurs doit correspondre au nombre de segments.

## Paramètres

<ParamField path="reservation_uuid" type="UUID" required>
  UUID de la réservation (route model binding sur colonne `uuid`).
</ParamField>

<ParamField body="passengers" type="object[]" required>
  Tableau des voyageurs (min 1).

  <ParamField body="passengers[].first_name" type="string" required>
    Prénom (max 120).
  </ParamField>
  <ParamField body="passengers[].last_name" type="string" required>
    Nom (max 120).
  </ParamField>
  <ParamField body="passengers[].phone" type="string">
    Téléphone (max 32).
  </ParamField>
  <ParamField body="passengers[].email" type="string">
    Email (max 255).
  </ParamField>
  <ParamField body="passengers[].document_type" type="string">
    `national_id`, `passport`, `consular_card`, ou `birth_certificate`. Requis pour les lignes internationales.
  </ParamField>
  <ParamField body="passengers[].document_number" type="string">
    Numéro de document (max 64). Requis pour les lignes internationales.
  </ParamField>
  <ParamField body="passengers[].nationality" type="string">
    Nationalité (code ISO 2, exactement 2 caractères). Requis pour les lignes internationales.
  </ParamField>
  <ParamField body="passengers[].birth_date" type="string">
    Date de naissance `YYYY-MM-DD`.
  </ParamField>
  <ParamField body="passengers[].seat_uuid" type="UUID">
    UUID du siège attribué.
  </ParamField>
</ParamField>

## Codes de réponse

| Code | Description |
|------|-------------|
| `200` | Voyageurs enregistrés — réservation mise à jour. |
| `401` | Token absent ou invalide. |
| `403` | Réservation appartenant à un autre utilisateur. |
| `422` | Réservation expirée, siège hors réservation, siège associé deux fois, nombre de voyageurs incorrect, ou documents manquants pour ligne internationale. |

<Warning>
  Chaque `seat_uuid` doit appartenir à la réservation et ne peut être associé qu'à **un seul** voyageur. Pour une **ligne internationale**, `document_type`, `document_number` et `nationality` sont obligatoires.
</Warning>
