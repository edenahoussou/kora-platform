# Passagers

`POST /api/v1/bookings/{reservation_uuid}/passengers`

Enregistre les voyageurs et associe chaque voyageur à un siège réservé. Le nombre de voyageurs doit correspondre au nombre de segments.

```bash
curl -X POST https://api.korabus.app/api/v1/bookings/9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb70/passengers \
  -H 'Authorization: Bearer 1|aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789abcdef' \
  -H 'Content-Type: application/json' \
  -d '{
    "passengers": [
      {
        "first_name": "Aïcha",
        "last_name": "HOUNKPÈ",
        "phone": "+2290197421860",
        "seat_uuid": "seat-002-uuid",
        "document_type": "passport",
        "document_number": "BJ0427851",
        "nationality": "BJ",
        "birth_date": "1994-04-18"
      }
    ]
  }'
```

### Paramètres

| Champ | Type | Requis | Description |
|-------|------|--------|-------------|
| `reservation_uuid` | UUID (path) | ✅ | UUID de la réservation. |
| `passengers` | array | ✅ | Tableau des voyageurs. |
| `passengers[].first_name` | string | ✅ | Prénom. |
| `passengers[].last_name` | string | ✅ | Nom. |
| `passengers[].phone` | string | ✅ | Téléphone avec indicatif. |
| `passengers[].seat_uuid` | UUID | ✅ | UUID du siège attribué. |
| `passengers[].document_type` | string | ❌* | Type de document (`passport`, `id_card`, ...). |
| `passengers[].document_number` | string | ❌* | Numéro de document. |
| `passengers[].nationality` | string | ❌* | Nationalité (code ISO 2). |
| `passengers[].birth_date` | string | ❌ | Date de naissance `YYYY-MM-DD`. |

> *Requis pour les **lignes internationales** (ex: Cotonou → Abidjan).

| Code | Description |
|------|-------------|
| `200` | Voyageurs enregistrés — réservation mise à jour. |
| `401` | Token absent ou invalide. |
| `403` | Réservation appartenant à un autre utilisateur. |
| `422` | Réservation expirée, siège hors réservation, siège associé deux fois, ou nombre de voyageurs incorrect. |

<Warning>
  Chaque `seat_uuid` doit appartenir à la réservation et ne peut être associé qu'à **un seul** voyageur. Une réservation expirée refuse l'enregistrement avec `422`.
</Warning>

<Info>
  Pour une **ligne internationale**, `document_type`, `document_number` et `nationality` sont obligatoires pour chaque voyageur.
</Info>
