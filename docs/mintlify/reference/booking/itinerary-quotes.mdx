# Devis d'itinéraire

Crée un devis serveur pour un itinéraire direct, avec correspondances, ou aller-retour. Pour un trajet direct, envoyez un seul leg. Pour un aller-retour, envoyez les legs `outbound` puis les legs `inbound` avec le champ `direction`. Le devis est lié à l'utilisateur authentifié et doit être utilisé avant son expiration.

## Requête

```json
{
  "passenger_count": 2,
  "promo_code": "KORA10",
  "legs": [
    {
      "leg_order": 1,
      "direction": "outbound",
      "departure_uuid": "departure-outbound-uuid",
      "origin_stop_uuid": "origin-stop-uuid",
      "destination_stop_uuid": "destination-stop-uuid"
    },
    {
      "leg_order": 2,
      "direction": "inbound",
      "departure_uuid": "departure-inbound-uuid",
      "origin_stop_uuid": "destination-stop-uuid",
      "destination_stop_uuid": "origin-stop-uuid"
    }
  ]
}
```

| Champ | Type | Requis | Description |
|---|---|---:|---|
| `passenger_count` | integer | non | Nombre de passagers, de 1 à 10. |
| `promo_code` | string | non | Code promotionnel (max 32 caractères, normalisé en majuscules). Appliqué après la tarification dynamique et avant la remise groupe. Le canal `mobile` est déduit automatiquement : une promotion limitée à un autre canal est refusée. |
| `legs` | array | oui | Un à six legs ordonnés (max 3 par direction). |
| `legs[].leg_order` | integer | non | Ordre 1-based ; l'ordre du tableau reste la référence. |
| `legs[].direction` | string | non | `outbound` (défaut) ou `inbound`. Requis pour les legs de retour d'un aller-retour. |
| `legs[].departure_uuid` | UUID | oui | Départ sélectionné. |
| `legs[].origin_stop_uuid` | UUID | oui | Arrêt origine du segment. |
| `legs[].destination_stop_uuid` | UUID | oui | Arrêt destination du segment. |

## Réponse

```json
{
  "data": {
    "itinerary_quote_uuid": "itinerary-quote-uuid",
    "trip_type": "round_trip",
    "total_amount": 24750,
    "currency": "XOF",
    "expires_at": "2026-09-10T08:00:00Z",
    "legs": [
      { "leg_order": 1, "direction": "outbound", "quote_uuid": "quote-leg-1-uuid", "final_amount": 15000 },
      { "leg_order": 2, "direction": "inbound", "quote_uuid": "quote-leg-2-uuid", "final_amount": 12500 }
    ],
    "pricing": {
      "subtotal_amount": 27500,
      "dynamic_adjustment_amount": 0,
      "promotion": {
        "uuid": "promotion-uuid",
        "code": "KORA10",
        "name": "Promo lancement",
        "discount_amount": 2750
      },
      "promotion_discount_amount": 2750,
      "group_discount": {},
      "passenger_allocations": [12375, 12375],
      "total_amount": 24750,
      "currency": "XOF"
    }
  }
}
```

| Champ | Type | Description |
|---|---|---|
| `pricing.promotion` | object \| null | Promotion appliquée (`uuid`, `code`, `name`, `discount_amount`), ou `null` sans code. |
| `pricing.promotion_discount_amount` | integer | Remise promotionnelle totale en XOF (0 sans code). |
| `pricing.total_amount` | integer | Montant final net de toutes les remises (tarification dynamique, promotion, remise groupe). |

Le montant et l'expiration retournés par le serveur sont la référence du hold. Le mobile ne doit pas reconstruire le snapshot tarifaire. La promotion est portée par le devis (`itinerary_quote_uuid`) jusqu'à la réservation : elle n'a pas à être renvoyée au hold ni au paiement, et sa consommation n'est comptabilisée qu'au paiement confirmé.

## Règles de validation aller-retour

- Le retour doit partir du point d'arrivée de l'aller.
- Le retour doit ramener le passager à son point de départ.
- Le retour ne peut pas partir avant l'arrivée de l'aller.
- Les legs `outbound` et `inbound` sont validés indépendamment (continuité, marge de correspondance).

## Codes de réponse

| Code | Description |
|---|---|
| `200` | Devis créé. |
| `401` | Authentification absente ou invalide. |
| `422` | Leg invalide, itinéraire discontinu, aller-retour incohérent, vente fermée ou devise incohérente. Code promo refusé sur le champ `promo_code` : `Ce code promotionnel est inconnu.`, `Ce code promotionnel n'est pas applicable actuellement.`, `Ce code promotionnel a atteint sa limite d'utilisation.` ou `Ce code promotionnel ne s'applique pas à cet itinéraire.` |
