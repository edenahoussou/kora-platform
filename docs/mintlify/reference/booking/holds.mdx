# Bloquer des sièges (hold)

Démarre un blocage de sièges (hold) après que le passager a confirmé sa sélection. Le hold ne démarre **pas** pendant la consultation du plan — uniquement à la confirmation explicite. La durée est contrôlée par `KORA_HOLD_TTL_MINUTES` (15 minutes par défaut).

## Paramètres

<ParamField body="departure_uuid" type="UUID" required>
  UUID du départ (doit exister dans `departures`).
</ParamField>

<ParamField body="origin_stop_uuid" type="UUID" required>
  UUID de l'arrêt d'origine (doit exister dans `stops`).
</ParamField>

<ParamField body="destination_stop_uuid" type="UUID" required>
  UUID de l'arrêt de destination (doit exister dans `stops`).
</ParamField>

<ParamField body="price_quote_uuid" type="UUID" required>
  UUID du devis créé précédemment (doit exister dans `price_quotes`).
</ParamField>

<ParamField body="seats" type="object[]" required>
  Tableau de sièges (min 1).

  <ParamField body="seats[].seat_uuid" type="UUID" required>
    UUID du siège (doit exister dans `seats`, **distinct** — pas de doublons).
  </ParamField>
  <ParamField body="seats[].passenger_index" type="integer">
    Index optionnel du passager associé.
  </ParamField>
</ParamField>

## Réponse

<ResponseField name="data" type="Reservation" required>
  <ResponseField name="uuid" type="UUID" required>UUID de la réservation.</ResponseField>
  <ResponseField name="status" type="string" required>`held`, `confirmed`, `paid`, `ticketed`, `boarded`, `cancelled`, ou `expired`.</ResponseField>
  <ResponseField name="expires_at" type="string">Expiration du hold (ISO 8601) ou `null`.</ResponseField>
  <ResponseField name="total_amount" type="integer" required>Montant total.</ResponseField>
  <ResponseField name="currency" type="string" required>Devise.</ResponseField>
  <ResponseField name="channel" type="string">`mobile`, `counter`, ou `web` — ou `null`.</ResponseField>
  <ResponseField name="departure_uuid" type="UUID">UUID du départ ou `null`.</ResponseField>
  <ResponseField name="price_quote_uuid" type="UUID">UUID du devis ou `null`.</ResponseField>
  <ResponseField name="passenger_count" type="integer">Nombre de passagers (si segments chargés).</ResponseField>
  <ResponseField name="segments" type="Segment[]">Segments réservés.</ResponseField>
  <ResponseField name="passengers" type="Passenger[]">Voyageurs enregistrés.</ResponseField>
</ResponseField>

## Codes de réponse

| Code | Description |
|------|-------------|
| `201` | Hold créé — `expires_at` indique la durée. |
| `401` | Token absent ou invalide. |
| `409` | Siège plus disponible (conflit de disponibilité, segment chevauchant). |
| `422` | Contrat quote/sièges incohérent, devis expiré, doublons de sièges, vente fermée. |

<Warning>
  Le nombre de sièges doit être **égal** à `passenger_count` du devis. Les doublons, un devis expiré ou un décalage de segment renvoient `422`. Un autre hold gagnant renvoie `409`.
</Warning>
