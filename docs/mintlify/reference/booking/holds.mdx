# Blocage de sièges (holds)

`POST /api/v1/bus/holds`

Démarre un blocage de sièges (hold) après que le passager a confirmé sa sélection. Le hold ne démarre **pas** pendant la consultation du plan — uniquement à la confirmation explicte. La durée est contrôlée par `KORA_HOLD_TTL_MINUTES` (15 minutes par défaut).

```bash
curl -X POST https://api.korabus.app/api/v1/bus/holds \
  -H 'Authorization: Bearer 1|aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789abcdef' \
  -H 'Content-Type: application/json' \
  -d '{
    "departure_uuid": "a3091549-9179-454e-8440-58179f2208df",
    "origin_stop_uuid": "6b72fe4a-5b40-307c-bc24-f79acf9a1bb9",
    "destination_stop_uuid": "8d94f06c-7d62-529e-de46-9bce1cbc3dd1",
    "price_quote_uuid": "9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d",
    "seats": [
      { "seat_uuid": "seat-002-uuid" },
      { "seat_uuid": "seat-004-uuid" }
    ]
  }'
```

```javascript
const res = await fetch('https://api.korabus.app/api/v1/bus/holds', {
  method: 'POST',
```

```json
{
  "message": "The given data was invalid.",
  "errors": {

```

### Paramètres

| Champ | Type | Requis | Description |
|-------|------|--------|-------------|
| `departure_uuid` | UUID | ✅ | UUID du départ. |
| `origin_stop_uuid` | UUID | ✅ | UUID de l'arrêt d'origine. |
| `destination_stop_uuid` | UUID | ✅ | UUID de l'arrêt de destination. |
| `price_quote_uuid` | UUID | ✅ | UUID du devis créé précédemment. |
| `seats` | array | ✅ | Tableau de `{ seat_uuid }`. Le nombre doit égal `passenger_count` du devis. |

### Codes de réponse

| Code | Description |
|------|-------------|
| `201` | Hold créé — `expires_at` indique la durée. |
| `401` | Token absent ou invalide. |
| `409` | Siège plus disponible (conflit de disponibilité, segment chevauchant). |
| `422` | Contrat quote/sièges incohérent, devis expiré, doublons de sièges. |

<Warning>
  Le nombre de sièges doit être **égal** à `passenger_count` du devis. Les doublons, un devis expiré ou un décalage de segment renvoient `422`. Un autre hold gagnant renvoie `409`.
</Warning>

<Info>
  Un même siège peut rester vendable sur deux segments **non chevauchants**. Les lectures de disponibilité ignorent déjà un hold arrivé à expiration, même si la commande planifiée n'a pas encore normalisé ses statuts.
</Info>
