# Réservations

## Récupérer une réservation

`GET /api/v1/bookings/{reservation_uuid}`

Récupère l'état serveur complet d'une réservation. À utiliser après une perte de session mobile pour reprendre le parcours sans reconstruire l'état local.

```bash
curl -X GET https://api.korabus.app/api/v1/bookings/9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb70 \
  -H 'Authorization: Bearer 1|aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789abcdef' \
  -H 'Accept: application/json'
```

```javascript
const res = await fetch('https://api.korabus.app/api/v1/bookings/9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb70', {
  headers: { 'Authorization': `Bearer ${token}` },
});
const { data } = await res.json();
```

```typescript
const res = await fetch(`https://api.korabus.app/api/v1/bookings/${reservationUuid}`, {
  headers: { 'Authorization': `Bearer ${token}` },
});
const data: KoraReservation = (await res.json()).data;
```

```dart
final res = await authDio.get('/api/v1/bookings/9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb70');
final reservation = res.data['data'];
```

**Réponse (200) :**

```json
{
  "data": {
    "uuid": "9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb70",
    "status": "held",
    "expires_at": "2026-08-20T08:15:00Z",
    "total_amount": 25000,
    "currency": "XOF",
    "channel": "mobile",
    "departure_uuid": "9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6e",
    "price_quote_uuid": "9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6f",
    "passenger_count": 2,
    "segments": [],
    "passengers": []
  }
}
```

### Paramètres

| Champ | Type | Requis | Description |
|-------|------|--------|-------------|
| `reservation_uuid` | UUID (path) | ✅ | UUID de la réservation. |

| Code | Description |
|------|-------------|
| `200` | Réservation retournée. |
| `401` | Token absent ou invalide. |
| `403` | Réservation appartenant à un autre utilisateur. |
| `404` | Réservation introuvable. |

<Info>
  La réponse contient le départ, le segment, les sièges, les voyageurs déjà enregistrés, le montant, la devise, le statut et `expires_at`. Le mobile ne doit **jamais** reconstruire la réservation depuis son état local.
</Info>

## Libérer un hold

`DELETE /api/v1/holds/{reservation_uuid}`

Libère volontairement le hold de l'utilisateur authentifié. Le statut passe à `cancelled`, les segments sont libérés et `released_at` est renseigné.

```bash
curl -X DELETE https://api.korabus.app/api/v1/holds/9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb70 \
  -H 'Authorization: Bearer 1|aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789abcdef'
```

```javascript
await fetch('https://api.korabus.app/api/v1/holds/9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb70', {
  method: 'DELETE',
  headers: { 'Authorization': `Bearer ${token}` },
});
```

```typescript
await fetch(`https://api.korabus.app/api/v1/holds/${reservationUuid}`, {
  method: 'DELETE',
  headers: { 'Authorization': `Bearer ${token}` },
});
```

```dart
await authDio.delete('/api/v1/holds/9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb70');
```

| Code | Description |
|------|-------------|
| `204` | Hold libéré — pas de body. |
| `401` | Token absent ou invalide. |
| `403` | Réservation appartenant à un autre utilisateur. |

<Warning>
  Un webhook de paiement tardif ne peut **pas** réactiver une réservation expirée : le paiement est marqué `failed` et les segments restent disponibles.
</Warning>
