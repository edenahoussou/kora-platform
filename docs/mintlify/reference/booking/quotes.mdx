# Créer un devis

> Cette page décrit le devis mono-segment legacy. Le parcours mobile recommandé utilise [Devis d'itinéraire](/reference/booking/itinerary-quotes), y compris pour un trajet direct à un seul leg.

Fige le tarif d'un segment demandé. La durée de validité est contrôlée par `KORA_QUOTE_TTL_MINUTES` (10 minutes par défaut). Le mobile doit conserver l'UUID du devis et le transmettre lors de la création du hold.

## Paramètres

<ParamField body="departure_uuid" type="UUID" required>
  UUID du départ sélectionné (doit exister dans la table `departures`).
</ParamField>

<ParamField body="origin_stop_uuid" type="UUID" required>
  UUID de l'arrêt d'origine du segment (doit exister dans la table `stops`).
</ParamField>

<ParamField body="destination_stop_uuid" type="UUID" required>
  UUID de l'arrêt de destination (doit exister dans la table `stops`).
</ParamField>

<ParamField body="service_class_uuid" type="UUID">
  UUID de la classe de service (doit exister dans `service_classes`). `null` = défaut.
</ParamField>

<ParamField body="passenger_count" type="integer">
  Nombre de passagers (min 1, max 10). Défaut si absent.
</ParamField>

## Codes de réponse

| Code | Description |
|------|-------------|
| `201` | Devis créé — `expires_at` indique la durée de validité. |
| `401` | Token Sanctum absent ou invalide. |
| `422` | Départ introuvable, segment invalide, vente fermée, ou `passenger_count` < 1. |

<Warning>
  Le `fare_preview` du départ est un **aperçu**. Le prix figé et contractuel s'obtient uniquement via cet endpoint.
</Warning>
