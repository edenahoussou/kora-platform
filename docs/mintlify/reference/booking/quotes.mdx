# Devis

`POST /api/v1/bus/quotes`

Fige le tarif d'un segment demandé. La durée de validité est contrôlée par `KORA_QUOTE_TTL_MINUTES` (10 minutes par défaut). Le mobile doit conserver l'UUID du devis et le transmettre lors de la création du hold.

```bash
curl -X POST https://api.korabus.app/api/v1/bus/quotes \
  -H 'Authorization: Bearer 1|aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789abcdef' \
  -H 'Content-Type: application/json' \
  -d '{
    "departure_uuid": "a3091549-9179-454e-8440-58179f2208df",
    "origin_stop_uuid": "6b72fe4a-5b40-307c-bc24-f79acf9a1bb9",
    "destination_stop_uuid": "8d94f06c-7d62-529e-de46-9bce1cbc3dd1",
    "service_class_uuid": null,
    "passenger_count": 2
  }'
```

```javascript
const res = await fetch('https://api.korabus.app/api/v1/bus/quotes', {

```

### Paramètres

| Champ | Type | Requis | Description |
|-------|------|--------|-------------|
| `departure_uuid` | UUID | ✅ | UUID du départ sélectionné. |
| `origin_stop_uuid` | UUID | ✅ | UUID de l'arrêt d'origine du segment. |
| `destination_stop_uuid` | UUID | ✅ | UUID de l'arrêt de destination. |
| `service_class_uuid` | UUID \| null | ❌ | Classe de service (null = défaut). |
| `passenger_count` | integer | ✅ | Nombre de passagers (≥ 1). |

### Codes de réponse

| Code | Description |
|------|-------------|
| `201` | Devis créé — `expires_at` indique la durée de validité. |
| `401` | Token Sanctum absent ou invalide. |
| `422` | Départ introuvable, segment invalide, ou `passenger_count` < 1. |

<Warning>
  Le `fare_preview` du départ est un **aperçu**. Le prix figé et contractuel s'obtient uniquement via cet endpoint. N'affichez jamais un prix définitif côté client avant la réponse du devis.
</Warning>

<Info>
  Le `snapshot` fige les paramètres tarifaires au moment de la création. Il garantit que le prix ne change pas même si le tarif évolue pendant la durée de validité.
</Info>
