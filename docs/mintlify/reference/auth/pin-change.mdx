# Changer de PIN

Change le PIN de l'utilisateur authentifié. Le PIN actuel doit être fourni. Le nouveau PIN doit être différent de l'actuel et confirmé.

## Paramètres

<ParamField body="current_pin" type="string" required>
  PIN actuel à 4 chiffres.
</ParamField>

<ParamField body="new_pin" type="string" required>
  Nouveau PIN à 4 chiffres (doit être différent de `current_pin`).
</ParamField>

<ParamField body="new_pin_confirmation" type="string" required>
  Doit être identique à `new_pin` (règle `confirmed`).
</ParamField>

<RequestExample>

```bash cURL
curl -X POST https://staging.koraexpress.app/api/v1/auth/pin/change \
  -H 'Authorization: Bearer 1|aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789abcdef' \
  -H 'Content-Type: application/json' \
  -d '{ "current_pin": "9775", "new_pin": "1234", "new_pin_confirmation": "1234" }'
```

## Codes de réponse

| Code | Description |
|------|-------------|
| `200` | PIN modifié. |
| `401` | Token absent ou invalide. |
| `422` | `current_pin` incorrect, `new_pin` identique à `current_pin`, ou validation échouée. |
