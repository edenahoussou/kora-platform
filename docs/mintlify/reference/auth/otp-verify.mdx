# Vérifier un OTP

Valide le code OTP à 6 chiffres saisi par l'utilisateur. Retourne un `verification_token` (64 caractères) à usage unique, à transmettre à l'action suivante (inscription, reset PIN, unlock).

## Paramètres

<ParamField body="otp_challenge_uuid" type="UUID" required>
  UUID retourné par `otp/request`.
</ParamField>

<ParamField body="purpose" type="string" required>
  Doit correspondre au `purpose` de la demande. Valeurs : `registration`, `login_new_device`, `pin_reset`, `account_unlock`.
</ParamField>

<ParamField body="code" type="string" required>
  Code OTP à 6 chiffres exactement.
</ParamField>

## Réponse

<ResponseField name="data" type="object" required>
  <ResponseField name="otp_challenge_uuid" type="UUID" required>
    UUID du challenge vérifié.
  </ResponseField>
  <ResponseField name="purpose" type="string" required>
    Contexte de la demande.
  </ResponseField>
  <ResponseField name="verification_token" type="string" required>
    Token à usage unique (64 caractères) pour l'action suivante.
  </ResponseField>
</ResponseField>

## Codes de réponse

| Code | Description |
|------|-------------|
| `200` | OTP vérifié — `verification_token` retourné. |
| `422` | `otp_expired`, `otp_invalid`, ou validation échouée. |
| `429` | Rate limit `auth-otp` dépassé (3/min). |
