# Modifier le profil

Met à jour le profil de l'utilisateur authentifié. `name` et `email` sont requis ; les autres champs sont optionnels.

## Paramètres

<ParamField body="name" type="string" required>
  Nom complet (max 120).
</ParamField>

<ParamField body="email" type="string" required>
  Email (format RFC, max 255, unique hors utilisateur courant).
</ParamField>

<ParamField body="phone" type="string">
  Téléphone (max 20).
</ParamField>

<ParamField body="country_code" type="string">
  Code pays (max 4).
</ParamField>

<ParamField body="birth_date" type="string">
  Date de naissance `YYYY-MM-DD` (avant aujourd'hui).
</ParamField>

## Codes de réponse

| Code | Description |
|------|-------------|
| `200` | Profil mis à jour. |
| `401` | Token absent ou invalide. |
| `422` | Validation échouée (email déjà utilisé, format invalide, etc.). |
