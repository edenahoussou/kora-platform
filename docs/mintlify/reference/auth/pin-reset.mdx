---
title: Réinitialiser le PIN
description: "Endpoint POST /api/v1/auth/pin/reset de l'API KORA BUS : réinitialisation du PIN oublié après vérification OTP avec le purpose pin_reset."
api: POST /api/v1/auth/pin/reset
authMethod: none
---

Réinitialise le PIN après vérification OTP avec `purpose: "pin_reset"`. Le nouveau PIN doit être confirmé.

## Paramètres

<ParamField body="otp_challenge_uuid" type="UUID" required>
  UUID du challenge OTP vérifié (purpose: `pin_reset`).
</ParamField>

<ParamField body="verification_token" type="string" required>
  Token retourné par `otp/verify` (64 caractères).
</ParamField>

<ParamField body="pin" type="string" required>
  Nouveau PIN à 4 chiffres.
</ParamField>

<ParamField body="pin_confirmation" type="string" required>
  Doit être identique à `pin` (règle `confirmed`).
</ParamField>

<RequestExample>

## Codes de réponse

| Code | Description |
|------|-------------|
| `200` | PIN réinitialisé. |
| `422` | `verification_token` invalide/expiré, ou PIN invalide. |
| `429` | Rate limit `auth-otp` dépassé (3/min). |
