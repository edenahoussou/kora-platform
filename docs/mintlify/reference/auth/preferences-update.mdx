# Modifier les préférences

Met à jour les préférences de l'utilisateur. Tous les champs sont optionnels — seuls les champs fournis sont modifiés (partial update).

## Paramètres

<ParamField body="push_notifications" type="boolean">
  Notifications push activées.
</ParamField>

<ParamField body="whatsapp_notifications" type="boolean">
  Notifications WhatsApp activées.
</ParamField>

<ParamField body="email_notifications" type="boolean">
  Notifications email activées.
</ParamField>

<ParamField body="locale" type="string">
  Langue : `fr` ou `en`.
</ParamField>

<ParamField body="theme" type="string">
  Thème : `light`, `dark`, ou `system`.
</ParamField>

<RequestExample>

```bash cURL
curl -X PUT https://staging.koraexpress.app/api/v1/auth/preferences \
  -H 'Authorization: Bearer 1|aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789abcdef' \
  -H 'Content-Type: application/json' \
  -d '{ "push_notifications": true, "whatsapp_notifications": false, "locale": "fr", "theme": "dark" }'
```

## Codes de réponse

| Code | Description |
|------|-------------|
| `200` | Préférences mises à jour. |
| `401` | Token absent ou invalide. |
| `422` | Valeur invalide (`locale` ou `theme` non supporté). |
