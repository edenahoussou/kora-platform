# Demander un OTP

Déclenche l'envoi d'un code OTP à 6 chiffres. Pour un compte existant, `identifier` accepte un email ou un numéro de téléphone normalisé ; WhatsApp est prioritaire lorsque le compte possède un téléphone, avec repli email. L'inscription (`registration`) reste basée sur l'email. Le `purpose` détermine le contexte et le rate limit applicable.

## Paramètres

<ParamField body="identifier" type="string" required>
  Email ou numéro de téléphone du compte. Les emails sont normalisés en minuscules et les numéros locaux ou internationaux au format international.
</ParamField>

<ParamField body="email" type="string">
  Alias rétrocompatible de `identifier`. Pour `registration`, l'adresse email est obligatoire. Ne pas envoyer les deux champs ensemble.
</ParamField>

<ParamField body="purpose" type="string" required>
  Contexte de la demande. Valeurs acceptées : `registration`, `login_new_device`, `pin_reset`, `account_unlock`.
</ParamField>

## Réponse

<ResponseField name="data" type="object" required>
  <ResponseField name="otp_challenge_uuid" type="UUID" required>
    UUID du challenge OTP. À transmettre à `otp/verify`.
  </ResponseField>
  <ResponseField name="purpose" type="string" required>
    Contexte de la demande (`registration`, `login_new_device`, `pin_reset`, `account_unlock`).
  </ResponseField>
  <ResponseField name="email" type="string" required>
    Email canonique du compte associé au challenge. La livraison peut avoir eu lieu par WhatsApp.
  </ResponseField>
  <ResponseField name="expires_at" type="string" required>
    Date d'expiration du challenge (ISO 8601).
  </ResponseField>
</ResponseField>

## Codes de réponse

| Code | Description |
|------|-------------|
| `202` | OTP mis en file pour WhatsApp ou email. |
| `404` | Compte inexistant pour `login_new_device`, `pin_reset` ou `account_unlock`. |
| `422` | `identifier` invalide, ambigu, ou téléphone fourni pour `registration`; `purpose` non supporté. |
| `429` | Rate limit `auth-otp` dépassé (3/min par IP + identifiant normalisé). |
