# Demander un OTP

Déclenche l'envoi d'un code OTP à 6 chiffres par email. Le `purpose` détermine le contexte et le rate limit applicable.

## Paramètres

<ParamField body="email" type="string" required>
  Email du passager (format RFC, max 255).
</ParamField>

<ParamField body="purpose" type="string" required>
  Contexte de la demande. Valeurs acceptées : `registration`, `login_new_device`, `pin_reset`, `account_unlock`.
</ParamField>

<RequestExample>

```bash cURL
curl -X POST https://staging.koraexpress.app/api/v1/auth/otp/request \
  -H 'Content-Type: application/json' \
  -d '{ "email": "passager@korabus.app", "purpose": "registration" }'
```

## Réponse

<ResponseField name="data" type="object" required>
  <ResponseField name="otp_challenge_uuid" type="UUID" required>
    UUID du challenge OTP. À transmettre à `otp/verify`.
  </ResponseField>
  <ResponseField name="purpose" type="string" required>
    Contexte de la demande (`registration`, `login_new_device`, `pin_reset`, `account_unlock`).
  </ResponseField>
  <ResponseField name="email" type="string" required>
    Email destinataire du code.
  </ResponseField>
  <ResponseField name="expires_at" type="string" required>
    Date d'expiration du challenge (ISO 8601).
  </ResponseField>
</ResponseField>

## Codes de réponse

| Code | Description |
|------|-------------|
| `202` | OTP envoyé par email. |
| `422` | `email` invalide ou `purpose` non supporté. |
| `429` | Rate limit `auth-otp` dépassé (3/min par IP + email). |
