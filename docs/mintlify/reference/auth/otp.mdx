# OTP

Les endpoints OTP permettent de vérifier l'identité d'un utilisateur par email avant une inscription, une connexion depuis un nouvel appareil, une réinitialisation de PIN ou un déverrouillage de compte.

## Demander un OTP

<Steps>
  <Step title="POST /api/v1/auth/otp/request">
    Envoie un code OTP à 6 chiffres par email. Retourne un `otp_challenge_uuid` à utiliser pour la vérification.

```bash
curl -X POST https://api.korabus.app/api/v1/auth/otp/request \
  -H 'Content-Type: application/json' \
  -d '{ "email": "passager@korabus.app", "purpose": "registration" }'
```

```javascript
const res = await fetch('https://api.korabus.app/api/v1/auth/otp/request', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ email: 'passager@korabus.app', purpose: 'registration' }),
});
const { data } = await res.json();
```

```typescript
const res = await fetch('https://api.korabus.app/api/v1/auth/otp/request', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ email: 'passager@korabus.app', purpose: 'registration' } satisfies OtpRequest),
});
const data: OtpChallenge = (await res.json()).data;
```

```dart
final res = await dio.post('/api/v1/auth/otp/request', data: {
  'email': 'passager@korabus.app',
  'purpose': 'registration',
});
final challengeUuid = res.data['data']['otp_challenge_uuid'];
```

**Réponse (202) :**

```json
{
  "data": {
    "otp_challenge_uuid": "6ff8f7f6-1eb3-3525-be4a-3932c805afed",
    "purpose": "registration",
    "email": "passager@korabus.app",
    "expires_at": "2026-08-17T13:10:00.000Z"
  }
}
```

**Réponse (429) — Rate limit :**

```json
{
  "error": {
    "code": "rate_limited",
    "message": "Trop de demandes OTP. Réessayez dans 60 secondes."
  }
}
```
  </Step>
</Steps>

### Paramètres

| Champ | Type | Requis | Description |
|-------|------|--------|-------------|
| `email` | string | ✅ | Adresse email de l'utilisateur. |
| `purpose` | string | ✅ | Contexte : `registration`, `login_new_device`, `pin_reset`, `account_unlock`. |

### Codes de réponse

| Code | Description |
|------|-------------|
| `202` | OTP envoyé par email. |
| `422` | Email invalide ou `purpose` non supporté. |
| `429` | Rate limit `auth-otp` dépassé (5/min). |

## Vérifier un OTP

<Steps>
  <Step title="POST /api/v1/auth/otp/verify">
    Valide le code OTP saisi par l'utilisateur. Retourne un `verification_token` à usage unique.

```bash
curl -X POST https://api.korabus.app/api/v1/auth/otp/verify \
  -H 'Content-Type: application/json' \
  -d '{ "otp_challenge_uuid": "6ff8f7f6-...", "purpose": "registration", "code": "569775" }'
```

```javascript
const res = await fetch('https://api.korabus.app/api/v1/auth/otp/verify', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ otp_challenge_uuid: challengeUuid, purpose: 'registration', code: '569775' }),
});
```

```typescript
const res = await fetch('https://api.korabus.app/api/v1/auth/otp/verify', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ otp_challenge_uuid: challengeUuid, purpose: 'registration', code: '569775' } satisfies OtpVerify),
});
```

```dart
final res = await dio.post('/api/v1/auth/otp/verify', data: {
  'otp_challenge_uuid': challengeUuid,
  'purpose': 'registration',
  'code': '569775',
});
final verificationToken = res.data['data']['verification_token'];
```

**Réponse (200) :**

```json
{
  "data": {
    "otp_challenge_uuid": "6ff8f7f6-1eb3-3525-be4a-3932c805afed",
    "purpose": "registration",
    "verification_token": "gzmiyvdljnikhwaykcmyuwpwlvqwrsitcpscqldzsnrwtujwvlxjklqppwqbewtn",
    "verified_at": "2026-08-17T13:05:00.000Z"
  }
}
```

**Réponse (422) — OTP expiré :**

```json
{
  "error": {
    "code": "otp_expired",
    "message": "Le code OTP a expiré. Demandez un nouveau code."
  }
}
```

**Réponse (422) — OTP invalide :**

```json
{
  "error": {
    "code": "otp_invalid",
    "message": "Le code OTP est incorrect."
  }
}
```
  </Step>
</Steps>

### Paramètres

| Champ | Type | Requis | Description |
|-------|------|--------|-------------|
| `otp_challenge_uuid` | UUID | ✅ | UUID retourné par `otp/request`. |
| `purpose` | string | ✅ | Doit correspondre au `purpose` de la demande. |
| `code` | string | ✅ | Code OTP à 6 chiffres saisi par l'utilisateur. |

### Codes de réponse

| Code | Description |
|------|-------------|
| `200` | OTP vérifié — `verification_token` retourné. |
| `422` | `otp_expired`, `otp_invalid`, ou `verification_token_invalid`. |
| `429` | Rate limit `auth-otp` dépassé. |

<Note>
  Le `verification_token` est à usage unique : il ne peut servir qu'à une seule action (inscription, reset PIN, unlock). Sa durée de validité est courte.
</Note>
