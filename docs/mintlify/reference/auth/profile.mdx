# Profil

Les endpoints `/me` permettent de consulter et modifier le profil de l'utilisateur authentifié.

## Consulter le profil

`GET /api/v1/auth/me`

```bash
curl -X GET https://api.korabus.app/api/v1/auth/me \
  -H 'Authorization: Bearer 1|aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789abcdef' \
  -H 'Accept: application/json'
```

```javascript
const res = await fetch('https://api.korabus.app/api/v1/auth/me', {
  headers: { 'Authorization': `Bearer ${token}` },
});
const { data } = await res.json();
```

```typescript
const res = await fetch('https://api.korabus.app/api/v1/auth/me', {
  headers: { 'Authorization': `Bearer ${token}` },
});
const data: KoraUser = (await res.json()).data.user;
```

```dart
final res = await authDio.get('/api/v1/auth/me');
print(res.data['data']['user']['name']);
```

**Réponse (200) :**

```json

  "data": {
    "user": {
      "uuid": "977e5426-8d13-3824-86aa-b092f8ae52c5",

      "phone": "+22902000001",
      "country_code": "BJ",
      "birth_date": null,
      "avatar_url": "https://api.korabus.app/media/avatars/123/thumb.jpg",
      "status": "active",
      "permissions": ["bookings.create", "bookings.view-own", "tickets.view"]
    }
  }
}
```

| Code | Description |
|------|-------------|
| `200` | Profil retourné. |
| `401` | Token absent ou invalide. |

## Modifier le profil

`PUT /api/v1/auth/me`

```bash
curl -X PUT https://api.korabus.app/api/v1/auth/me \
  -H 'Authorization: Bearer 1|aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789abcdef' \
  -H 'Content-Type: application/json' \
  -d '{ "name": "Aïcha Hounkpè", "phone": "+2290197421860", "country_code": "BJ", "birth_date": "1994-04-18" }'
```

```javascript
const res = await fetch('https://api.korabus.app/api/v1/auth/me', {
  method: 'PUT',
  headers: { 'Authorization': `Bearer ${token}`, 'Content-Type': 'application/json' },
  body: JSON.stringify({ name: 'Aïcha Hounkpè', phone: '+2290197421860', country_code: 'BJ' }),
});
```

```typescript
const res = await fetch('https://api.korabus.app/api/v1/auth/me', {
  method: 'PUT',
  headers: { 'Authorization': `Bearer ${token}`, 'Content-Type': 'application/json' },
  body: JSON.stringify({ name, phone, country_code, birth_date } satisfies UpdateProfileRequest),
});
```

```dart
await authDio.put('/api/v1/auth/me', data: {
  'name': 'Aïcha Hounkpè',
  'phone': '+2290197421860',
  'country_code': 'BJ',
  'birth_date': '1994-04-18',
});
```

### Paramètres

| Champ | Type | Requis | Description |
|-------|------|--------|-------------|
| `name` | string | ❌ | Nom complet. |
| `phone` | string | ❌ | Téléphone avec indicatif. |
| `country_code` | string | ❌ | Code pays ISO 2 (ex: `BJ`). |
| `birth_date` | string | ❌ | Date de naissance `YYYY-MM-DD`. |

| Code | Description |
|------|-------------|
| `200` | Profil mis à jour. |
| `401` | Token absent ou invalide. |
| `422` | Validation échouée. |
