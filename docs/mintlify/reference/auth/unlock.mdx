# Déverrouiller un compte

Déverrouille un compte verrouillé après plusieurs PIN incorrects. Requiert une vérification OTP avec `purpose: "account_unlock"`.

## Paramètres

<ParamField body="otp_challenge_uuid" type="UUID" required>
  UUID du challenge OTP vérifié (purpose: `account_unlock`).
</ParamField>

<ParamField body="verification_token" type="string" required>
  Token retourné par `otp/verify` (64 caractères).
</ParamField>

<RequestExample>

```bash cURL
curl -X POST https://staging.koraexpress.app/api/v1/auth/unlock \
  -H 'Content-Type: application/json' \
  -d '{
    "otp_challenge_uuid": "6ff8f7f6-1eb3-3525-be4a-3932c805afed",
    "verification_token": "gzmiyvdljnikhwaykcmyuwpwlvqwrsitcpscqldzsnrwtujwvlxjklqppwqbewtn"
  }'
```

## Codes de réponse

| Code | Description |
|------|-------------|
| `200` | Compte déverrouillé. |
| `422` | `verification_token` invalide/expiré. |
| `429` | Rate limit `auth-otp` dépassé (3/min). |
