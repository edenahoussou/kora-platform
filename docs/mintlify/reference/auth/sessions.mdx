# Sessions & PIN

Ces endpoints gèrent le cycle de vie d'une session utilisateur : inscription, connexion, réinitialisation de PIN, déverrouillage de compte, changement de PIN et déconnexion.

## Compléter l'inscription

`POST /api/v1/auth/register/complete`

Finalise la création d'un compte après vérification OTP. L'utilisateur choisit un PIN à 4 chiffres et enregistre son appareil. L'API crée le compte et émet un token Sanctum.

```bash
curl -X POST https://api.korabus.app/api/v1/auth/register/complete \
  -H 'Content-Type: application/json' \
  -d '{
    "otp_challenge_uuid": "6ff8f7f6-1eb3-3525-be4a-3932c805afed",
    "verification_token": "gzmiyvdljnikhwaykcmyuwpwlvqwrsitcpscqldzsnrwtujwvlxjklqppwqbewtn",
    "pin": "9775",
    "device_name": "iPhone 15 Pro",
    "platform": "ios",
    "device_fingerprint": "a1b2c3d4e5f6",
    "push_token": "ExponentPushToken[xxxxxxxxxxxxxxxxxxxxxx]"
  }'
```

```javascript
const res = await fetch('https://api.korabus.app/api/v1/auth/register/complete', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    otp_challenge_uuid: challengeUuid,
    verification_token: verificationToken,
    pin: '9775',
    device_name: 'iPhone 15 Pro',
    platform: 'ios',
    device_fingerprint: 'a1b2c3d4e5f6',
  }),
});
const { data } = await res.json();
const token = data.token;
```


### Paramètres

| Champ | Type | Requis | Description |
|-------|------|--------|-------------|
| `otp_challenge_uuid` | UUID | ✅ | UUID du challenge OTP vérifié. |
| `verification_token` | string | ✅ | Token retourné par `otp/verify`. |
| `pin` | string | ✅ | PIN à 4 chiffres choisi par l'utilisateur. |
| `device_name` | string | ✅ | Nom lisible de l'appareil. |
| `platform` | string | ✅ | `ios` ou `android`. |
| `device_fingerprint` | string | ✅ | Empreinte unique de l'appareil. |
| `push_token` | string | ❌ | Token push (FCM/APNs) pour notifications. |

### Codes de réponse

| Code | Description |
|------|-------------|
| `201` | Compte créé, token émis. |
| `422` | `verification_token_invalid`, PIN invalide, ou email déjà utilisé. |
| `429` | Rate limit `auth-login` dépassé (10/min). |

## Connexion

`POST /api/v1/auth/login`

Connecte un utilisateur existant avec email + PIN. Si la connexion provient d'un **nouvel appareil**, l'API retourne `202` avec `requires_otp: true` au lieu d'un token.

```bash
curl -X POST https://api.korabus.app/api/v1/auth/login \
  -H 'Content-Type: application/json' \
  -d '{ "email": "passager@korabus.app", "pin": "9775", "device_name": "Samsung S24", "platform": "android", "device_fingerprint": "f6e5d4c3b2a1" }'
```

```javascript
const res = await fetch('https://api.korabus.app/api/v1/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ email: 'passager@korabus.app', pin: '9775', device_name: 'Samsung S24', platform: 'android', device_fingerprint: 'f6e5d4c3b2a1' }),
});
```

```typescript
const res = await fetch('https://api.korabus.app/api/v1/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ email, pin, device_name, platform, device_fingerprint } satisfies LoginRequest),
});
```

```dart
final res = await dio.post('/api/v1/auth/login', data: {
  'email': 'passager@korabus.app',
  'pin': '9775',
  'device_name': 'Samsung Galaxy S24',
  'platform': 'android',
  'device_fingerprint': 'f6e5d4c3b2a1',
});
```

**Réponse (200) — Appareil connu :**

```json
{
  "data": {
    "token": "2|xYzAbCdEfGhIjKlMnOpQrStUvWxYz0123456789abcdef",
    "token_type": "Bearer",
    "expires_at": "2026-08-24T13:10:00.000Z",
    "user": { "uuid": "977e5426-...", "email": "passager@korabus.app", "status": "active" },
    "device": { "uuid": "b4102650-...", "name": "Samsung Galaxy S24", "status": "trusted" }
  }
}
```

**Réponse (202) — Nouvel appareil :**

```json
{
  "data": {
    "requires_otp": true,
    "otp_challenge_uuid": "c5216701-9e2a-4f3b-8c1d-0a4e5f6789ab",
    "purpose": "login_new_device",
    "expires_at": "2026-08-17T13:15:00.000Z"
  }
}
```

**Réponse (422) — Identifiants invalides :**

```json
{ "error": { "code": "invalid_credentials", "message": "Identifiants invalides." } }
```

**Réponse (423) — Compte verrouillé :**

```json
{
  "error": {
    "code": "account_locked",
    "message": "Le compte est temporairement bloqué après plusieurs tentatives incorrectes.",
    "locked_until": "2026-08-17T13:30:00.000Z"
  }
}
```

### Paramètres

| Champ | Type | Requis | Description |
|-------|------|--------|-------------|
| `email` | string | ✅ | Email de l'utilisateur. |
| `pin` | string | ✅ | PIN à 4 chiffres. |
| `device_name` | string | ✅ | Nom de l'appareil. |
| `platform` | string | ✅ | `ios` ou `android`. |
| `device_fingerprint` | string | ✅ | Empreinte de l'appareil. |
| `otp_challenge_uuid` | UUID | ❌ | Requis si nouvel appareur (après OTP). |
| `verification_token` | string | ❌ | Requis si nouvel appareil. |

### Codes de réponse

| Code | Description |
|------|-------------|
| `200` | Connexion réussie — token émis. |
| `202` | Nouvel appareil — `requires_otp: true`, OTP requis. |
| `422` | `invalid_credentials` ou validation échouée. |
| `423` | `account_locked` — déverrouillage OTP requis. |
| `429` | Rate limit `auth-login` dépassé. |

<Warning>
  **Nouvel appareil** : enchaînez `otp/request` (purpose: `login_new_device`) → `otp/verify` → `login` avec `otp_challenge_uuid` + `verification_token`.
</Warning>

## Réinitialiser le PIN

`POST /api/v1/auth/pin/reset`

Réinitialise le PIN après vérification OTP (purpose: `pin_reset`).

```bash
curl -X POST https://api.korabus.app/api/v1/auth/pin/reset \
  -H 'Content-Type: application/json' \
  -d '{ "otp_challenge_uuid": "6ff8f7f6-...", "verification_token": "gzmiyvdljnik...", "pin": "1234" }'
```

```dart
await dio.post('/api/v1/auth/pin/reset', data: {
  'otp_challenge_uuid': challengeUuid,
  'verification_token': verificationToken,
  'pin': '1234',
});
```

**Réponse (200) :**

```json
{
  "data": {
    "user": { "uuid": "977e5426-...", "email": "passager@korabus.app", "status": "active" }
  }
}
```

| Code | Description |
|------|-------------|
| `200` | PIN réinitialisé. |
| `422` | `verification_token_invalid` ou PIN invalide. |

## Déverrouiller un compte

`POST /api/v1/auth/unlock`

Déverrouille un compte après vérification OTP (purpose: `account_unlock`).

```bash
curl -X POST https://api.korabus.app/api/v1/auth/unlock \
  -H 'Content-Type: application/json' \
  -d '{ "otp_challenge_uuid": "6ff8f7f6-...", "verification_token": "gzmiyvdljnik..." }'
```

```dart
await dio.post('/api/v1/auth/unlock', data: {
  'otp_challenge_uuid': challengeUuid,
  'verification_token': verificationToken,
});
```

| Code | Description |
|------|-------------|
| `200` | Compte déverrouillé. |
| `422` | `verification_token_invalid`. |

## Changer de PIN (authentifié)

`POST /api/v1/auth/pin/change`

Change le PIN de l'utilisateur authentifié. Requiert le PIN actuel.

```bash
curl -X POST https://api.korabus.app/api/v1/auth/pin/change \
  -H 'Authorization: Bearer 1|aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789abcdef' \
  -H 'Content-Type: application/json' \
  -d '{ "current_pin": "9775", "new_pin": "1234" }'
```

```dart
await authDio.post('/api/v1/auth/pin/change', data: {
  'current_pin': '9775',
  'new_pin': '1234',
});
```

| Code | Description |
|------|-------------|
| `200` | PIN modifié. |
| `401` | Token absent ou invalide. |
| `422` | `current_pin` incorrect ou `new_pin` invalide. |
| `423` | Compte verrouillé après tentatives. |

## Déconnexion

`POST /api/v1/auth/logout`

Révoque le token courant. Les autres appareils restent connectés.

```bash
curl -X POST https://api.korabus.app/api/v1/auth/logout \
  -H 'Authorization: Bearer 1|aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789abcdef'
```

```dart
await authDio.post('/api/v1/auth/logout');
```

| Code | Description |
|------|-------------|
| `204` | Token révoqué — pas de body. |
| `401` | Token absent ou invalide. |
