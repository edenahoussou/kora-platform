# Lister les appareils

Retourne la liste des appareils enregistrés sur le compte de l'utilisateur authentifié, via `UserDeviceResource`.

<RequestExample>

```bash cURL
curl -X GET https://staging.koraexpress.app/api/v1/auth/devices \
  -H 'Authorization: Bearer 1|aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789abcdef' \
  -H 'Accept: application/json'
```

```javascript JavaScript
const res = await fetch('https://staging.koraexpress.app/api/v1/auth/devices', {
  headers: { 'Authorization': `Bearer ${token}` },
});
const { data } = await res.json();
```

```typescript TypeScript
const res = await fetch('https://staging.koraexpress.app/api/v1/auth/devices', {
  headers: { 'Authorization': `Bearer ${token}` },
});
const data: UserDevice[] = (await res.json()).data;
```

```dart Dart
final res = await authDio.get('/api/v1/auth/devices');
final devices = res.data['data'] as List;
```

</RequestExample>

## Réponse

<ResponseField name="data" type="UserDevice[]" required>
  <ResponseField name="uuid" type="UUID" required>Identifiant unique de l'appareil.</ResponseField>
  <ResponseField name="name" type="string" required>Nom de l'appareil.</ResponseField>
  <ResponseField name="platform" type="string" required>`android`, `ios`, `web`, ou `unknown`.</ResponseField>
  <ResponseField name="trusted_at" type="string">Date de confiance (ISO 8601) ou `null`.</ResponseField>
  <ResponseField name="last_seen_at" type="string">Dernière activité (ISO 8601) ou `null`.</ResponseField>
  <ResponseField name="status" type="string" required>`active` ou `revoked`.</ResponseField>
</ResponseField>

## Codes de réponse

| Code | Description |
|------|-------------|
| `200` | Liste des appareils. |
| `401` | Token absent ou invalide. |
