---
title: Marquer toute l’inbox comme lue
description: "Marquer comme lues toutes les notifications passager non lues."
api: POST /api/v1/auth/passenger/notifications/read-all
---

Marque comme lues toutes les notifications passager non lues appartenant à l’utilisateur authentifié.

```bash
curl -X POST 'https://staging.koraexpress.app/api/v1/auth/passenger/notifications/read-all' \
  -H 'Authorization: Bearer <token-de-session>' \
  -H 'Accept: application/json'
```

```json
{"data":{"updated":2,"unread":0}}
```
