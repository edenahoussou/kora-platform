---
title: Vérification de mise à jour Passager
description: "Vérifier au démarrage si une mise à jour mobile est disponible ou obligatoire."
api: GET /api/v1/apps/{id}/update
---

Cette route est **publique** (`auth: none`) et est appelée par l’application mobile Passager avant toute connexion. Elle reste la source serveur pour une mise à jour obligatoire ou une version minimale imposée ; le flux Play in-app update reste géré côté mobile Android.

## Paramètres

### Path

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `app` | string | Oui | Pour l’app Passager : `passenger-mobile` ou `passenger_mobile`. |

### Query

| Paramètre | Type | Requis | Description |
| --- | --- | --- | --- |
| `platform` | `android` \| `ios` | Oui pour `passenger-mobile` | Plateforme de l’appareil. |
| `environment` | `production` \| `staging` | Non | Environnement cible. Défaut serveur : `production`. |
| `version` | string | Non | Version installée (`1.3.2` ou `1.3.2+37`). |
| `build` | integer | Non | Build number installé ; il prime sur le build inclus dans `version`. |

## Exemple curl

```bash
curl 'https://staging.koraexpress.app/api/v1/apps/passenger-mobile/update?platform=android&environment=production&version=1.3.2&build=37' \
  -H 'Accept: application/json'
```

## Réponse 200 — aucune release confirmée

```json
{
  "data": null,
  "meta": {
    "server_time": "2026-01-01T00:00:00+00:00"
  }
}
```

## Erreurs

| Statut | Description |
| --- | --- |
| `404` | Application inconnue. |
| `422` | `platform` manquant/invalide pour une release store, ou champ de version/build invalide. |
| `429` | Limite de débit atteinte pour cette IP. |

```json
{
  "message": "The platform field is required for store releases."
}
```
